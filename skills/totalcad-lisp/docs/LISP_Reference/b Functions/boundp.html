boundp

(boundp item)

Check if an item has a bound value.

This function verifies whether the specified symbol contains an assigned value in the current environment. Returns T for defined non-nil values, and nil for unbound symbols or those explicitly set to nil.

Examples

Code Result
(setqx 8ynil)
(boundp y) 		nil
(setq a 7.9b6)
(boundp b) 		T

Note

The boundp function checks for variable definition, whereas null evaluates if a variable is unbound or nil.
