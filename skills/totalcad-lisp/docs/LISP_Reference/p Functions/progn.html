progn

(progn statement1 statement2 ...)

Executes a sequence of expressions sequentially.

Processes each statement in order and outputs the result of the final expression.

Frequently used to group multiple operations within logical constructs like if statements. While if conditions only permit a single consequent expression, progn enables bundled execution of multiple statements. The return value corresponds to the outcome of the terminal expression in the sequence.

Examples

Code Result
(progn (+ 2 3) (* 7 8)) 56
