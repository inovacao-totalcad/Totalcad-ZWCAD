polar

(polar base_point angle distance)

Computes a 3D polar coordinate point relative to a base point.

This function calculates coordinates by applying a rotation (in radians) to the base_point, then displacing it along the resulting directional vector by the given distance. Returns a list representing the new XYZ position.

Examples

Code Result
(polar '(3 4) 89 3) (4.53053 6.58021)
(polar '(8.4 4.5) 0.89 3.2) (10.4141 6.98663)

Note

The angle is expressed in radians relative to the positive x-axis, increasing counterclockwise.
