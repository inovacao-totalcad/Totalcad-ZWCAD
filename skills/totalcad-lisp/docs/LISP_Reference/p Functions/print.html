print

(print [expression [file-descriptor]])

Outputs expressions with structured formatting.

  • Similar to prin1 but adds a newline character preceding the expression and a trailing space following it. Control characters are displayed literally without interpretation. This function does not execute escape sequences.

  • When a file descriptor is provided, formatted output is redirected to the specified file with the same formatting rules applied.

Examples

Code Prints Result
(print "hello") "hello" "hello"
(print "\nName:") "\nName:" "\nName:"
(print "Thank you") "Thank you" "Thank you"

Note

The print function in LISP differs from similar output functions (such as prin1 or princ) by automatically inserting a newline character before the expression and a space following it.
