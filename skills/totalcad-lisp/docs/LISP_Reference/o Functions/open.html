open

(open filename mode)

Initializes a file stream for data operations.

This routine establishes a connection between the specified file and subsequent I/O functions. The filename parameter must contain a valid system path and target filename.

Upon successful access, the function provides a unique 0x-prefixed hexadecimal file handle (8 characters) that must be assigned to a variable via setq. All subsequent file operations must reference this handle rather than the original filename.

Access modes (case-sensitive lowercase strings):

Mode Operation
"r" Read-only access. Returns nil if file is unavailable
"w" Write access with truncation. Creates new file if needed
"a" Append mode. Writes to end of existing content

Examples

Code Result
(open "gpdialog.dcl" "r") <File-stream #x93b43bd0:48158b00>

Note

  • In append mode, new data is added to the end of the existing file.

  • LISP only reads ASCII files (no binary files) using sequential access (no random access).

  • To separate subdirectory names, you use either two backslashes ( \\ ) or a single forward slash ( / ).

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (setq f (open "D:/tmp/?????中望/?????ZW.txt" "r" "utf8"))

  • When LISPSYS is 1, the result is "#<File-stream #x93b43bd0:48158b00>".
  • When LISPSYS is 0, the function execution failed
