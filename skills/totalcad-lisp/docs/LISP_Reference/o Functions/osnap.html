osnap

(osnap point mode)

Calculates 3D coordinates using ZWCAD's geometric snap features.

This function locates precise points on drawing entities through specified snap types. Multiple snap modes can be combined in the mode parameter for concurrent detection.

Mode Code Snap Target
"ext" EXTension path alignment
"gcen" Geometric CENTer of polygons
"app" APParent intersection in current view
"nod" NODe points
"para" PARAllel trajectory
"mid" MIDdle of linear objects
"tan" TANgent to curves
"qua" QUAdrant of circles
"int" True 3D INTersection
"cen" CENter of arcs/circles
"end" END points
"ins" INSertion base points
"off" Disable active snaps

Provide approximate coordinates near the target geometry through the point parameter. Returns nil if no valid snap point matches the criteria.

Examples

Code Result
(osnap '(5 5)"mid") (8.00000 8.00000 0.000000)

Note

The permissible gap between the initial selection point and the object is controlled by the APERTURE system variable, adjustable within a 1-50 pixel range.
