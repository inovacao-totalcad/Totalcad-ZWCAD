getpoint

(getpoint [base_point] [message])

Prompts the user to select a point in the drawing area.

This function halts execution until the user provides a coordinate location. When a base point argument is supplied, it establishes a dynamic reference marker that visually connects to the current cursor position. Input can be provided through keyboard entry or interactive screen selection.

An optional message string displays custom instructional text in the command line interface. The function returns either a 3D point list or nil if input is canceled.

Examples

Code Result
(getpoint "Pick a point: ") Select a point:3,4
(3.00000 4.00000 0.000000)
