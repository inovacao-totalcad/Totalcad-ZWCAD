getcorner

(getcorner point [message])

Prompts the user to define the opposite corner of a rectangular area.

This command requires an initial base point (point) and dynamically displays a resizable rectangle as the cursor moves. The base coordinate is typically acquired via another input method like getpoint or user-selected coordinates.

An optional guidance message (message) can be displayed to the user. Note: This input does not accept LISP expressions as valid responses.

Examples

Code Result
(getcorner '(4.894 1.548) "Select corner: ") (290.880 -175.471 0.000000)
(getcorner '(0 0)) (386.491 135.879 0.000000)

Note

The base point aligns with the active UCS coordinate system. Specified z-values are disregarded, with the current elevation applied instead.
