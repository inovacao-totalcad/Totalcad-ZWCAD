getfiled

(getfiled title default_filename extension mode_bits)

Opens a platform-specific file selection dialog for user input.

This routine launches the system's native file picker interface enabling users to navigate and select files from storage.

The title parameter defines the window caption text. Use empty quotes (" ") for no title - this argument cannot be omitted.

default_filename sets the initially highlighted filename in the input field. Pass " " to start with an empty field, but null values are prohibited.

extension filters visible files: specify formats like "dwg" or "lsp". Use "*" to show all files, or " " for no extension filter.

mode_bits combines numeric options through bitwise addition to control dialog behavior:

Bit Value Functionality
1 Display overwrite confirmation for existing files
2 Hide the command-line alternative button
16 Enable extension modification in input field
32 Resolve file path using ZWCAD support directories

Combine values for multiple features. Example: Setting 17 (1+16) enables overwrite warnings and extension editing capabilities.

Examples

Code
(getfiled "Drawing Files" " " "DWG" 2)
(getfiled "Lisp Files" "sample.lsp" "LSP" 6)
