getkword

(getkword [message])

Requests textual input constrained to predefined keywords.

This function requires prior configuration using (initget [options] [keywords])(IDR_205) to establish allowable responses. Typical applications include enforcing specific choices like "vertical"/"horizontal" or validating numeric ranges such as 5-20. Keywords are case-insensitive when compared using (equal) with appropriate flags(IDR_166).

Implementation involves two phases: First, define acceptable responses through initget's keyword string parameter. Second, invoke getkword with an optional message parameter. ZWCAD automatically generates a dialog containing validated options and a termination button.

Invalid entries trigger an automated retry sequence with "Invalid input. Retry:" notification. Empty responses (Enter key) yield nil unless explicitly permitted through initget flags. The function enforces keyword matching and provides type validation for numerical constraints.

Returns nil immediately if no valid keywords were registered through initget prior to execution.
