getangle

(getangle [point] [prompt])

Requests angular input from the user.

This function accepts angle values in the configured unit format and converts them to radians. When a base point is provided, it calculates the angle from the ANGBASE-defined reference axis to the specified direction vector, following a counterclockwise-positive convention regardless of the ANGDIR system setting.

Angular measurement always starts from the ANGBASE orientation and progresses counterclockwise, with returned values in radians. User input is restricted to direct angle specifications - LISP expressions are not permitted.

An optional prompt string can customize the input request message displayed to the user.

Examples

Code Result
(getangle "Input an angle:")
 Input an angle:45
0.785398

Note

The getangle function calculates angles relative to the base direction specified in the Units settings. For angle measurements aligned with the absolute coordinate system (East = 0°), employ the getorient function instead.
