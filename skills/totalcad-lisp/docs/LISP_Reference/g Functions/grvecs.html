grvecs

(grvecs vector-lists [trans])

Renders temporary guideline vectors in the active viewport.

Similar to grdraw but optimized for batch operations, this function displays multiple transient vectors that clear automatically during viewport refreshes or command executions.

The vector-lists parameter accepts nested lists defining line segments with color attributes. Each vector entry requires sequential coordinate pairs preceded by an optional color code:

Color Code Visual Effect
Unspecified Uses current context color
-1 High-contrast selection indicator
0-255 ZWCAD color index values
≥256 XOR overlay (invert background pixels)

Note: All coordinates are interpreted in the current UCS unless modified by an optional transformation matrix.

Examples

Code Result
(grvecs '( 5 (0.0 0.0) (1.0 1.0))) nil
(grvecs '( 2 (5.0 6.0) (5.5 16.5) 4 (5.5 16.5) (10.0 10.0))) nil
