start_dialog

(start_dialog)

Launches the color selection dialog interface.

This routine activates a graphical dialog and processes user interactions such as button clicks. The exit status is determined by values received from done_dialog:

Status Code Description
1 Action confirmed with OK selection
0 Operation canceled by user
-1 Dialog terminated via term_dialog function

Examples

Code
(start_dialog )

Note

  • A dialog box is first initialized by the new_dialog function.

  • The order of calling a dialog box is as follows:

  • load_dialog

  • new_dialog

  • action_tile, start_image, start_list, etc (perform all dialog box initialization, such as associating an action with a tiles, creating an image, and making the lists for list boxes)

  • start_dialog
