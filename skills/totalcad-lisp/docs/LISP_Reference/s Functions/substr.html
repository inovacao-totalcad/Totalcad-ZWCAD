substr

(substr string start [length])

Retrieve a specified segment from a string.

This operation extracts a character sequence from a source string, returning a value usable like any string data. The extraction begins at the start index and spans according to optional parameters.

The start parameter specifies the initial extraction position, with string indexing beginning at 1 (contrary to zero-based list indexing). If start exceeds the string's character count, an empty string is returned.

The optional length parameter defines the maximum characters to extract. Omission results in capturing all characters from the start position through the string's termination. Excessive length values are automatically truncated to valid character limits without generating errors.

Examples

Code Result
(substr "congratulation" 4) "gratulation"
(substr "angthing" 4) "thing"

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (substr "你好中望" 1 2)

  • When LISPSYS is 1, the result is ""你好"".
  • When LISPSYS is 0, the result may not be as expected.
