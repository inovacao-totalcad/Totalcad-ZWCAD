setfunhelp

(setfunhelp c:name [file [topic [command]]])

Links a custom command to the Help system, enabling context-sensitive assistance when users request support for the command.

Returns

The registered command name string if successful; nil otherwise.

Arguments

c:name

Command definition string requiring the 'C:' prefix.

file

Help documentation file path (CHM format recommended).

topic

Specific help section identifier within the file.

command

Command name string without 'C:' prefix.

After implementing your command and help resources, use this function to establish the connection. The sample below demonstrates loading assistance for a 'test' command:

Usage Example

Implementation Outcome
(defun c:test1()
(defun c:test()(getstring "\nTEST: ") (princ))
(setfunhelp "c:test" "ZWCAD_Dev.chm" "line")
) 		Opens the 'line' help topic in ZWCAD_Dev.chm when assistance is requested during command execution.

Important

Ensure command definition (defun) precedes setfunhelp invocation in your code sequence.
