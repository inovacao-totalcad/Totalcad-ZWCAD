ssgetfirst

(ssgetfirst)

Identifies entities that are highlighted or have active grips.

This function returns information about entities in two states: those marked with grips without selection, and those simultaneously highlighted and gripped. Grips appear as interactive squares around entities when preselected, enabling direct editing through control points.

ssgetfirst outputs a list containing two selection sets. The first set represents entities with active grips outside the current selection, while the second set contains entities actively selected with visible grips.
