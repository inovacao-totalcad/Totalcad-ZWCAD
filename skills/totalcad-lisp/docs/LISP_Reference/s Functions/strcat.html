strcat

(strcat string1 [string2] ...)

Combines multiple input strings into a single concatenated string.

This function performs string concatenation by merging the provided strings sequentially. All parameters must be string values, and the result is returned as a unified string.

Examples

Code Result
(strcat "zw" "cad") "zwcad"
(strcat "H" "e" "l" "l" "o") "Hello"
