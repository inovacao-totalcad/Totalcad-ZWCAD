snvalid

(snvalid symbol [flag])

Validates symbol naming compliance for ZWCAD tables.

This function checks symbol names against current EXTNAMES system variable settings (0=legacy rules, 1=extended rules). Prohibited characters in all modes include:

  • Non-printable ASCII characters below 32
  • Empty string or whitespace-only names
  • Leading/trailing pipe (|) characters
Pipe Character Handling
Flag Value Validation Behavior
0 Reject names containing |
1 Allow internal | characters

Supported tables include block definitions, layers, linetypes, and other named object dictionaries.

Examples

Code Result
(snvalid "A") T
(snvalid "a|b" 1) T
(snvalid "ab|" 1) nil
(snvalid "a|b" 0) nil
