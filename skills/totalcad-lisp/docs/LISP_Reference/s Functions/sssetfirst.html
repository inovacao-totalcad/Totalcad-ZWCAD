(sssetfirst grip-set [pick-set])

Activates graphical grips and highlighting for specified selections.

Displays modification grips (small square handles) on grip-set entities while highlighting objects in pick-set. Grips provide interactive control points for editing geometric elements.

Implementation Note

The ssgetfirst function should be employed to generate valid grip-set and pick-set parameters before invoking this command.

Examples

Code
(sssetfirst ss)
