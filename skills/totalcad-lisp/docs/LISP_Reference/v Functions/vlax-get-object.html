vlax-get-object

(vlax-get-object prog-id)

Returns a running instance of an application object.

Use this function when you want to get an instance of an application, and an object of the type is specified by <Component> (see the argument description) to be returned. If there is instance of the specified object currently running, this function returns a VLA-object representing the instance of the specified application, otherwise nil.

The function accepts one argument:

Argument Meaning
prog-id A string containing the programmatic identifier of the desired ActiveX object, its format is as following:
<Vendor>.<Component>.<Version>
eg: excel.application.12

Examples

Code Result
(vlax-get-object "Excel.application") #<VLA-OBJECT _Application 201374>
