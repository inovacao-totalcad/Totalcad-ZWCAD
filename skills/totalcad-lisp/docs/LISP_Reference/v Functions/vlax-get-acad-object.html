vlax-get-acad-object

(vlax-get-acad-object)

Returns the top level ZWCAD application object (all of the ActiveX objects' root) for the current ZWCAD session.

This function always returns a VLA-object, and it needn't any arguments.

Examples

Code Result
(vlax-get-acad-object) #<VLA-OBJECT IZWCADApplication 5ac3d9c>
