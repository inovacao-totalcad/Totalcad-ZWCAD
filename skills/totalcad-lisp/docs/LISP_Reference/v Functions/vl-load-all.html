vl-load-all

(vl-load-all filename)

Load that file.

The filename argument represents the name of the loaded file. You need enter the file type. The function does not assume a file type. The filename can include the directory path. If one is not included, ZWCAD searches the support file search paths specified in the configuration.

Examples

Code Result
(vl-load-all "test1.lsp") C:T3
(vl-load-all "c:/test2.lsp") C:T3
