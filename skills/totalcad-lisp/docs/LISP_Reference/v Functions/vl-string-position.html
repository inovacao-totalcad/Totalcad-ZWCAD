vl-string-position

(vl-string-position char-codestr [start-pos [reverse-search]])

Locates the first occurrence of a character matching a specified ASCII code within a string, returning its zero-indexed position.

This function scans the input string and returns the numerical index of the target character code. The optional start-pos parameter defines the search's starting index when provided. If reverse-search is set to T, scanning progresses backward from either the string's end or the specified start-pos. Returns nil if no matching character is detected.

Examples

Code Result
(vl-string-position (ascii "e")"abcde") 4
(vl-string-position (ascii "e")"eabcde" 2) 5
(vl-string-position (ascii "e")"eabcde" nil T) 5

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (VL-STRING-POSITION (ascii "?") "中望?")

  • When LISPSYS is 1, the result is "2".
  • When LISPSYS is 0, the result may not be as expected.
