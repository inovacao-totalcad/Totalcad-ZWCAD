vlax-variant-change-type

(vlax-variant-change-type var type)

Returns the value of a variant after changing its data type.

If the var can be converted to the specified data type successfully, this function returns the value of var after being converted to the specified data type, otherwise nil.

The function accepts two arguments:

Argument Meaning
var A variable whose value is a variant.
type The type of variant. It can be one of the following constants:
  • vlax-vbEmpty (0)Uninitialized (default value)
  • vlax-vbNull (1)Contains no valid data
  • vlax-vbInteger (2)Integer
  • vlax-vbLong (3)Long integer
  • vlax-vbSingle (4)Single-precision floating-point number
  • vlax-vbDouble (5)Double-precision floating-point number
  • vlax-vbString (8)String
  • vlax-vbBoolean (11)Boolean
  • vlax-vbArray (8196)Array
    This parameter can be a string constant or an integer constant(in parentheses), but the integer constant aren't suggested using for the lisp codes' compatibility.

    • Examples

    Code Result
    (setq var_float (vlax-make-variant 12.3 vlax-vbSingle))
    (setq var_string (vlax-variant-change-type var_float vlax-vbString))
    (vlax-variant-value var_string)     		"12.3"
