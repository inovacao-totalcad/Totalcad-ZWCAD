vlax-import-type-library

(vlax-import-type-library :tlb-filename filename [:methods-prefix mprefix :properties-prefix pprefix :constants-prefix cprefix])

Imports information from a type library.

If the specified type library is valid, this function imports the information from the type library and returns T, otherwise nil.

Parameters

filename

A string naming the type library. And the files can be divided as the following type:

  • type library (.tlb) and object library (.olb) files.

  • the .exe files.

  • the libraries files (.dll) included type libraries resources.

  • the compound files that include type libraries.

  • the files style that can be explained by the LoadTypeLib API.

The function accepts one argument with a symbol at least:

Argument Meaning
filename A string naming the type library.
mprefix Prefix to be used for method wrapper functions.
pprefix Prefix to be used for property wrapper functions.
cprefix Prefix to be used for constants contained in the type library.

Examples

Code Result
(setq sysdrv (getenv "systemdrive"))
(setq tlbfile (findfile (strcat sysdrv "\\Program Files\\Microsoft Office\\Office12\\Excel.exe")))
(vlax-import-type-library
:tlb-filename tlbfile
:methods-prefix "msxl-"
:properties-prefix "msxl-"
:constants-prefix "msxl-")
(if msxl-xl24HourClock
(princ "\nLoading Microsoft Excel type library complete.")
