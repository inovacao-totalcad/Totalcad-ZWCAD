vlr-add

(vlr-add reactor)

Adds a disabled reactor object.

If the reactor argument represents a reactor object, this function returns a reactor object even if the reactor object has been enabled, or it will prompt "error: bad argument type".

The function accepts one argument:

Argument Meaning
reactor A reactor object.
