vlax-ldata-test

(vlax-ldata-test data)

Determines whether data can be saved over a session boundary.

If the specified data can be saved as LISP data over a session boundary, this function returns T, otherwise returns nil.

The function accepts one argument:

Argument Meaning
data Any LISP data to be tested.

Examples

Code Result
(vl-load-com)
(vlax-ldata-test "ZWCAD_BOM_MXL1") 		T
(defun drawcircle()
(command "circle" pause 20.0)
(princ)
)
(vl-load-com)
(vlax-ldata-test drawcircle) 		nil
