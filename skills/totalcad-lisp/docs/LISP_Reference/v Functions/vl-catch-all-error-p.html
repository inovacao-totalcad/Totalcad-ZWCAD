vl-catch-all-error-p

(vl-catch-all-error-p arg)

Determines whether an argument is an error object returned from vl-catch-all-apply.

If the supplied argument is an error object returned from vl-catch-all-apply, this function returns T; otherwise nil.

The function accepts one arguments:

Argument Meaning
arg Any argument

Examples

Code Result
(setq catchit (vl-catch-all-apply '/ (list 100 0)))
(vl-catch-all-error-p catchit) 		T
