vlax-remove-cmd

(vlax-remove-cmd global-name)

Removes the command from ZWCAD's command set which has been added by vlax-add-cmd function.

If global-name argument represents a command which has been added to ZWCAD's command set by vlax-add-cmd function, this function remove the command and returns T, otherwise nil.

The function accepts two optional arguments:

Argument Meaning
global-name A string representing the command to be removed.

Examples

Code Result
(vlax-remove-cmd "hello") T
(vlax-remove-cmd "ZWCAD") nil

"ZWCAD" isn't a command name added by vlax-add-cmd function.
