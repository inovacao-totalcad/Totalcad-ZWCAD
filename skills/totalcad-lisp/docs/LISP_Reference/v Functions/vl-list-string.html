vl-list->string

(vl-list->string char-codes-list)

Returns a string.

This function converts the character ASCII code(an integer) to string and combines these strings .

The character ASCII code(an integer) must be less than 256.

Examples

Code Result
(vl-list->string '(97 23)) "a\027"
(vl-list->string '(2 23 98)) "\002\027b"

(vl-string->list string)

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (vl-list->string (list 20013 26395))

  • When LISPSYS is 1, the result is ""中望"".
  • When LISPSYS is 0, the function execution failed
