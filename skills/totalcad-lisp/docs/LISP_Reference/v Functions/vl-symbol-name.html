vl-symbol-name

(vl-symbol-name symbol)

Returns the name of the symbol in the form of capital string.

If the datatype of the symbol argument is SYM, this function returns the name of the symbol in the form of capital string, otherwise, returns an error message like "bad argument type".

Examples

Code Result
(vl-symbol-name t) "T"
(vl-symbol-name 'S::StartUp) "S::STARTUP"
(vl-symbol-name 12) error: "bad argument type"
