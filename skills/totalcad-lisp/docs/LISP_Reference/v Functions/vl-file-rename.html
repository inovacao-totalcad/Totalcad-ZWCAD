vl-file-rename

(vl-file-rename old-filename new-filename)

Modifies the name of an existing file.

This function changes the original filename (old-filename) to the specified target filename (new-filename) on the filesystem.

Returns T when the filename modification is completed successfully. Returns nil if the operation fails due to invalid paths or system restrictions.

Examples

Code Result
(vl-file-rename "D:/test.txt" "D:/abc.txt") T

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (VL-FILE-RENAME "D:/tmp/?????中望/?????.txt" "D:/tmp/?????中望/?????ZW.txt")

  • When LISPSYS is 1, the result is "T".
  • When LISPSYS is 0, the result may not be as expected.
