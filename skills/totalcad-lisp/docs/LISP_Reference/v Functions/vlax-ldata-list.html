vlax-ldata-list

(vlax-ldata-list dict)

Lists LISP data in a specified drawing dictionary.

If the specified dictionary is existed and there're some keys in it, this function returns an associative list consisting of pairs (key . value), otherwise nil.

The function accepts one argument:

Argument Meaning
dict A VLA-object, ZWCAD drawing entity object, or a string naming a global dictionary.

Examples

Code Result
(vl-load-com)
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Bolts")
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL2" "Nuts")
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL3" "Pins")
(vlax-ldata-list "ZWCAD_BOM_DICTIONARY") 		(("ZWCAD_MXB_MXL1" . "Bolts") ("ZWCAD_MXB_MXL2" . "Nuts") ("ZWCAD_MXB_MXL3" . "Pins"))
