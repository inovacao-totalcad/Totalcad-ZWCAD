vlax-ldata-put

(vlax-ldata-put dict key data)

Stores LISP data to a drawing dictionary or a drawing entity dictionary.

If the specified key is existed in the specified dictionary, this function corrects the data of the specified key and returns the data value, otherwise creates the key in the specified dictionary to store the LISP data and returns the data value too.

The function accepts three arguments:

Argument Meaning
dict A VLA-object(ZWCAD drawing entity object), or a string naming a global dictionary.
key A string specifying the dictionary key.
data LISP data to be stored in the key.

Examples

Code Result
(vl-load-com)
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Chinaweal Longteng") 		"Chinaweal Longteng"
