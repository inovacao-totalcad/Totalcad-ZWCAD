vlax-get-or-create-object

(vlax-get-or-create-object prog-id)

Returns a running instance of an application object, or creates a new instance if the application is not currently running.

Use this function when you want to get or create an instance of an application, and an object of the type specified by <Component> (see the argument description) to be returned. Even though there isn't instance of the specified object currently running, this function returns a VLA-object representing the instance of the specified application.

The function accepts one argument:

Argument Meaning
prog-id A string containing the programmatic identifier of the desired ActiveX object, its format is as following:
<Vendor>.<Component>.<Version>
eg: excel.application.12

Examples

Code Result
(vlax-get-or-create-object "Excel.application") #<VLA-OBJECT _Application 201374>
(vlax-get-or-create-object "zwcad.drawing") #<VLA-OBJECT IZcadDocument 231ee255198>
