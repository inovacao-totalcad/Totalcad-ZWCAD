vl-registry-write

(vl-registry-write reg-key [val-name val-data])

Makes a new Windows registry key.

This function makes a new Windows registry key and sets a registry entry and registry data. If successful, its value is returned as a registry data; if failed, nil is returned.

The function will be supply a default value for the registry entry when val-name is not supplied or is nil. If val-name is exist and val-data is not exist, this function will be set a nil in val-data.

Examples

Code Result
(vl-registry-write "HKEY_CURRENT_USER\\NewKey" "" "data1") "data1"
(vl-registry-write "HKEY_CURRENT_USER\\NewKey" "tmp" "data2") "data2"
