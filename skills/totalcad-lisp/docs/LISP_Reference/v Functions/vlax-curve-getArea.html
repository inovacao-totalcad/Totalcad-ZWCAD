vlax-curve-getArea

(vlax-curve-getArea curve-obj)

Returns the area of a curve.

If area makes sense to the curve-obj, this function returns a real number representing the area of the curve, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result
(vlax-curve-getArea curve-obj) 138.979.

NOTE

The measured curve must be closed, otherwise vlax-curve-getArea function will returns 0.
