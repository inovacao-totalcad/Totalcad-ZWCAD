vlax-safearray-put-element

(vlax-safearray-put-element var index... value)

Sets an element's value of an array.

If the specified var is an array, and the specified indexes of the element make sense to the array, this function assigns the specified value to the specified element and returns its value, otherwise prompts an error message.

The function accepts three arguments at least:

Argument Meaning
var A safearray.
index A integer representing the indexes of the element in the array, the number of element argument depends on the number of the dimension in the array.
value The value to assign the safearray element.

Examples

Code Result
(setq matrix (vlax-make-safearray vlax-vbString '(0 . 2) '(0 . 2)))
(vlax-safearray-fill matrix '(("00" "01" "02") ("10" "11" "12") ("20" "21" "22")))
(vlax-safearray-put-element matrix 1 2 "ZwCAD")
(vlax-safearray->list matrix) 		(("00" "01" "02") ("10" "11" "ZwCAD") ("20" "21" "22"))
