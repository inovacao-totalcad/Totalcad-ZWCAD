vlax-get-property

(vlax-get-property vla-object propertyName)

Gets a VLA-object's property.

If the property makes sense to the vla-object, this function returns the specified property's value, otherwise displays an error message.

The function accepts two arguments:

Argument Meaning
vla-object A VLA-object.
propertyName The VLA-object's property (vlax-dump-object function can be used to query a VLA-object's properties).

Examples

Code Result
(setq testobj (car (entsel "\nselect a entity:")))
(setq vlaObj (vlax-ename->vla-object testobj))
(vlax-get-property vlaObj 'Radius) 		If you select circle or arc, these codes return the radius' value, otherwise prompt "error: bad argument".
