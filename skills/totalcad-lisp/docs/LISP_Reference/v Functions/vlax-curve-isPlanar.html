vlax-curve-isPlanar

(vlax-curve-isPlanar curve-obj)

Determines whether there is a planar contains all vertexes of the curve.

If there is at least one planar contains all vertexes of the curve, this function returns T, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result 
(command "3dpoly" "-6.8,4.3,0.0" "-5.2,-3.0,3.0"
	 "5.2,-3.0,0.0" "0.0,6.0,0.0" "")
(setq curve-obj (vlax-ename->vla-object (entlast)))
(vlax-curve-isPlanar curve-obj)
nil

The vertexes of the 3D polyline constitutes a tetrahedron, so there isn't any planar contains these vertexes. 

(command "circle" "-6.8,4.3,0.0" 6.0)
(setq curve-obj (vlax-ename->vla-object (entlast)))
(vlax-curve-isPlanar curve-obj)
T

curve-obj argument represents a circle, all point on the curve is in a same planar.
