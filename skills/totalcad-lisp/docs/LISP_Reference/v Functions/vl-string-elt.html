vl-string-elt

(vl-string-elt string position)

Retrieves the ASCII value of a character from a specified string index.

The function evaluates the character at the given zero-based position and returns its numerical ASCII equivalent. Invalid positions will trigger an error response. Position numbering starts at index 0 for the first character.

Examples

Code Result
(vl-string-elt "Hello" 3) 108
(vl-string-elt "Hello" 8) error: invalid argument(VL-STRING-ELT "Hello" 8)

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (vl-string-elt "你好中望" 2)

  • When LISPSYS is 1, the result is "20013".
  • When LISPSYS is 0, the result may not be as expected.
