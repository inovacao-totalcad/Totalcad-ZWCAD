vlax-3D-point

(vlax-3D-point list) or (vlax-3D-point x y [z])

Constructs a variant, the actual datatype of which is a array including two or three double value.

Parameters

list

A list of 2 or 3 numbers for a point.

X Y Z

Numbers representing X,Y and Z coordinates of a point.

Notes

The function requires a minimum of two double-precision values in the provided list. Supplying fewer than two elements triggers an error, preventing variant creation. If the list contains more than three elements, only the first three entries will be used to generate the variant.

Examples

Code Result
(vlax-3D-point '(25.6 38.6 10.0)) #<variant 8197 ...>
(vlax-3D-point '(25.6 38.6)) #<variant 8197 ...>
(vlax-3D-point 25.6 38.6 0) #<variant 8197 ...>
