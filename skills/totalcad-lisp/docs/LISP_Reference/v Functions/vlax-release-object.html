vlax-release-object

(vlax-release-object obj)

Releases a argument with VLA object data type.

If obj argument represents a VLA object, this function releases the object and returns 0, otherwise ZWCAD reports "error: bad argument type". When the obj argument is released, it can' t be used to access the VLA object again (its value is #<VLA-OBJECT 00000000>), but the VLA object still exists. Before invoking vlax-release-object function to release VLA object, you'd better invoke vlax-object-released-p function to check if this object has been released already.

The function accepts one argument:

Argument Meaning
obj A VLA object.

NOTE

vlax-release-object function only releases the argument representing a VLA object, and the VLA object still exists.
