vl-list*

(vl-list* object[object]...)

Makes a new list.

This function creates a list from the objects specified.

The possible return values:

objects Result
a single atom An atom
all atoms A dotted pair
the last argument is an atom A dotted list
none of the previous statements is true A list

Note

If the final argument is an atom while the preceding conditions remain unmet, the third scenario will yield a dotted pair list.

Examples

Code Result
(vl-list* 3 4 0) (3 4 . 0)
(vl-list* '(1 3 5) 4) ((1 3 5) . 4)
(vl-list* 3) 3
