vector_image

(vector_image start_x start_y end_x end_y color_code)

Renders a directional line segment within a dialog tile, extending from initial coordinates (start_x, start_y) to terminal coordinates (end_x, end_y). The coordinate system originates at the top-left corner with (0,0).

Input Arguments

start_x
Horizontal position of the starting point
start_y
Vertical position of the starting point
end_x
Horizontal position of the endpoint
end_y
Vertical position of the endpoint
color_code
Numeric representation for line color, including these special codes:
Code Application
-2 Adopts the drawing area's background color
-15 Matches the dialog panel's background shade
-16 Uses the dialog's primary text color
-18 Applies the default line color of dialogs

Output

Provides the numerical color identifier used for rendering

Examples

Code Result
(vector_image 0 0 2 5 -2) nil
