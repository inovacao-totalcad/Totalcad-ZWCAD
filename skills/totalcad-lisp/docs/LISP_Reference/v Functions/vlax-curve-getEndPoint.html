vlax-curve-getEndPoint

(vlax-curve-getEndPoint curve-obj)

Returns the endpoint of the curve.

If endpoint makes sense to the curve-obj, this function returns a 3D point list representing an endpoint, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result
(command "line" "0,0" "20,30" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(command "ucs" "O" "100,100")
(vlax-curve-getEndPoint vla_object) 		(20.0000 30.0000 0.000000) (in WCS)

Note

This function outputs the endpoint's WCS coordinates regardless of the active UCS.
