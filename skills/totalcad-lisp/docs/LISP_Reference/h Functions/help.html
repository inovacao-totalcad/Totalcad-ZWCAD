help

(help [filename [topic [flag]]])

Opens the ZWCAD assistance interface.

This command launches the interactive help system. Optional parameters modify the behavior as follows:

  • filename: Specifies an HLP documentation file to access.

  • topic: Indicates a specific help entry or command reference.

  • flag: Controls the display mode with these options:

    • help_contents: Shows the root help menu
    • help_helponhelp: Displays navigation instructions
    • help_partialkey: Activates text search functionality

Examples

Code Result
(help "ZwHelp.exe") "ZwHelp.exe"
