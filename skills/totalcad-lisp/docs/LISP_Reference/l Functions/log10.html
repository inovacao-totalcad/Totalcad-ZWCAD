log10

(log10 num)

Computes the base-10 logarithm of a positive number

This routine calculates the logarithm with base 10 for valid positive inputs. The result is returned as a real value. Negative numbers are not accepted as parameters.

Examples

Code Result
(log10 3) 0.477121
(log10 5.9) 0.770852

Note

The exp function serves as the mathematical inverse of the logarithm operation.
