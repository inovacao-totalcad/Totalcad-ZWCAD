log

(log number)

Computes the natural logarithm (base e) of a number.

Despite the common mathematical notation "ln", this function uses "log" to represent the natural logarithm. Negative input values are not permitted. The output is always returned as a real number, even for integer inputs.

Examples

Code Result
(log 3) 1.09861
(log 5.9) 1.77495

Note

The exponential function serves as the inverse of the logarithmic function.
