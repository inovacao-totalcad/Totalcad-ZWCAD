last

(last list)

Retrieves the final element of a specified list.

This operation extracts the terminal member from the given list. The returned value maintains its original data structure - a single element is returned as-is, while nested lists will preserve their structure in the output.

Examples

Code Result
(last '(1 2 3)) 3
(last '("one" "two")) "two"

Note

This function requires careful handling in certain scenarios. For instance, when attempting to extract the z-coordinate from a point value, the absence of elevation data might lead to unintentionally returning the y-coordinate instead. To prevent such errors, consider strategically combining car and cdr functions for reliable coordinate parsing.
