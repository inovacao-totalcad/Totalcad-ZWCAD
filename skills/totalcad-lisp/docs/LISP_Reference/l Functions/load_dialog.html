load_dialog

(load_dialog dcl_filename)

Initializes a dialog interface definition from specified DCL file.

This routine registers a Dialog Control Language (DCL) configuration with ZWCAD's interface system. Successful execution is a prerequisite for displaying custom dialog components within the application. The dcl_filename parameter should specify the target definition file including its extension.

The function yields these status indicators:

Code Description
1 DCL configuration loaded successfully
-1 File access failure (invalid path or missing permissions)

Note: Multiple DCL files require separate load operations. Ensure file paths comply with ZWCAD's security protocols.

Examples

Code Result
(load_dialog "gpdialog.dcl") 1
