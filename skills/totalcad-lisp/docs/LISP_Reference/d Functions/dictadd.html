dictadd

(dictadd ename symbol newobj)

Inserts a non-graphical entity into a specified dictionary.

This function associates a named object (newobj) with a dictionary resource (ename), using the provided symbol as its unique access key. The symbol must represent an unused identifier within the target dictionary. Dictionary entries cannot be shared across multiple dictionaries - each object is permanently bound to a single dictionary container.

Examples

(setq dict (list '(0 . "DICTIONARY")'(100 . "AcDbDictionary")))
(setq new_name (entmakes dict)) (setq nmdict (namedobjdict )) (dictadd nmdict "NEW_DICTIONARY" new_name ))
