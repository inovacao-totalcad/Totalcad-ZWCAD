dos_filep

(dos_filep filename)

Tests for the existence of a file.

Parameters

filename
The source filename.

Returns

T if filename exists.
nil if filename does not exist, or on error.

Example

Code Result
(dos_filep "C:\\Program Files\\ZWCAD 2012\\ZWCAD.exe") T
(dos_filep "C:\\ZWCAD 2012\\drawing1.dwg") nil
