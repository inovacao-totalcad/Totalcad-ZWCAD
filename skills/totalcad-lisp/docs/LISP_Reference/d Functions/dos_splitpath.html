dos_splitpath

(dos_splitpath path)

Split full path to four parts.

Parameters

path
The full path.

Returns

Table with the following four elements if successful.
drive with (:).
dir with (\\) at begin and end.
filename without extension.
extension with (.) at begin.
nil on error.

Example

Code Result
(dos_splitpath "C:\\Program Files\\ZWCAD2025\\zwcad.exe") ("C:" "\\Program Files\\ZWCAD2025\\" "zwcad" ".exe")
(dos_splitpath "C:\\Program Files\\ZWCAD2025\\") ("C:" "\\Program Files\\ZWCAD2025\\" "" "")
