dimy_tile

(dimy_tile key)

Retrieves the vertical measurement of a dialog component.

When combined with dimx_tile, this function calculates both axis dimensions for the interface element specified by key. The returned values are particularly useful for graphical operations within dialog panels, including but not limited to rendering shapes with vector_image functions.

Examples

Code
(dimy_tile "image")

Note

  • The dimension returned is one less than the size, since the dimension begins at 0. Thus, for the example above, the size of the tile is 16 x 16.

  • The key is a case-sensitive string.
