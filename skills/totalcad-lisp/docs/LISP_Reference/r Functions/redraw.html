redraw

(redraw [ename [mode]])

Updates the graphical display viewport or specified entity.

This routine regenerates visual representation of the drawing area or modifies the display state of a particular object. Temporary graphics elements (e.g., those created with grdraw) will be cleared upon execution.

When an entity name (ename) is specified, its visual presentation can be altered using these mode parameters:

Mode Effect
1 Default display refresh for the entity
2 Temporarily hides the entity's visibility
3 Applies highlight styling (using HIGHLIGHT variable)
4 Disables highlighting effects

Negative mode values exclusively impact primary components of composite elements (blocks/polylines), leaving sub-entities unaffected. Always returns nil.

Examples

Code Result
(command "line" '(6 7) '(8 9) "")
(setq ent (entlast))
(redraw ent 3) 		nil
