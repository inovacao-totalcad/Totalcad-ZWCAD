read-line

(read-line [file-descriptor])

Returns a complete text line from a file stream.

This function provides sequential line reading capability, offering improved convenience compared to character-by-character processing. It retrieves string-formatted content through a file descriptor created by the open(open filename mode)(IDR_237) function. Each invocation advances the file position to subsequent data entries.

Examples

Code Result
(setq file (open "sample_file.txt" "r"))
(setq c(read-line file))
(setq d(read-line file))
"First Line Content"
"Second Line Content"

Note

  • The read-line function automatically moves to the next line in the file; it returns the next line from the file.

  • When read-line reaches the end of the file, it returns nil.

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (open "read-line.txt" "r") (read-line f) (close f)

  • When LISPSYS is 1, the result is "你好".
  • When LISPSYS is 0, the result may not be as expected.
