regapp

(regapp appname)

Registers an application identifier for extended data management.

This routine creates an entry in the drawing's APPID symbol table to organize application-specific extended entity data. Multiple registrations are permitted per drawing, enabling different programs to manage their proprietary data attachments independently.

Application names support alphanumeric and special characters (no spaces), limited to 31 characters. Returns nil if the specified application identifier already exists in the current drawing.

Examples

Code Result
(regapp "SectionViewStyle") nil
(regapp "ZWCAD-TEST") "ZWCAD-TEST"
