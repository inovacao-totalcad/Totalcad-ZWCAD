chr

(chr integer)

Returns the ASCII character representation of an integer.

This function translates numeric ASCII codes into their equivalent printable characters. Valid input must be an integer between 0 and 127.

Examples

Code Result
(chr 68) "D"
(chr 95) "_"
(chr 56) "8"

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (chr 20320)

  • When LISPSYS is 1, the result is ""你"".
  • When LISPSYS is 0, the result may not be as expected.
