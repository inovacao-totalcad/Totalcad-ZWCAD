cond

(cond (test-expr1 consequent1 ...) ...)

Evaluates conditions sequentially and executes corresponding expressions.

This conditional branching construct processes each clause by evaluating the test expression. When a true value is encountered, subsequent expressions in that clause are executed, returning the value of the last evaluated expression.

  • If the initial test-expr yields nil, the function evaluates the subsequent condition test-expr.

  • Execution skips clauses with logically false test expressions until finding a true condition.

  • Returns nil if all test expressions evaluate to nil.

  • Clauses without consequent expressions return the evaluated value of their test-expr when selected.

Examples

Code
(setq NUM 289)
(cond
((> NUM 200 ) (alert "Severe"))
((> NUM 100 ) (alert "Very High"))
((> NUM 50 ) (alert "High"))
((> NUM 25 ) (alert "Medium"))
)
