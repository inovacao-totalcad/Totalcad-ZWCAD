(>)(greater than operator)

(>arg1 arg2 ...)

Evaluates whether the initial argument exceeds all subsequent arguments in value.

This comparison operator returns either T (true) or nil (false) based on these rules:

  • Returns T only if arg1 > arg2, and arg2 > arg3 (where applicable), continuing this pattern through all provided arguments.
  • Returns nil immediately when encountering any argument that equals or exceeds its predecessor in the sequence.

Supports numeric comparisons and lexicographical string comparisons. For multiple arguments, strict descending order is required for a T result.

Examples

Code Result
(> 45 27 ) T
(> "A" "B") nil
(> -3 -15) T
(> 90 23 9) T
(> 17) T

Note

This function returns the logical inverse result of the <= (Less Than or Equal To) operation.
