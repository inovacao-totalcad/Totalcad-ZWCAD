(-)(Subtraction operator)

(-number1 number2 ...)

Subtracts subsequent values from the initial argument.

This operator calculates the numerical reduction effect. For two arguments, it yields number1 minus number2. With multiple arguments, it sequentially deducts each subsequent value from the accumulated result, equivalent to subtracting the collective sum of number2 onward from number1.

Examples

Code Result
(- 30 20) 10
(- 1.3 2.4) -1.10000
(- 60 -10 50) 20
(- 3) -3
(-) 0
