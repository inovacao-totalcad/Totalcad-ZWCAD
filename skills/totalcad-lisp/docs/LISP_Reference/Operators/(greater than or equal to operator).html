(>=)(greater than or equal to operator)

(>=item1 item2 ...)

Evaluates whether each preceding item is at least as large as the subsequent ones.

This comparison operator checks numeric or string relationships in sequence:

  • Returns T if item1 is numerically/lexically ≥ item2 for pairwise comparisons
  • For multiple arguments, verifies non-increasing sequence (item1 ≥ item2 ≥ ...)
  • Yields nil if any right-hand item exceeds its immediate left neighbor

Supports both numerical values and case-sensitive string comparisons.

Examples

Code Result
(>= 45 27 ) T
(>= "A" "B") nil
(>= -3 -15) T
(>= 90 90 9) T
(>= 17) T

Note

This function evaluates whether a value is not smaller than another, reversing the logic of the < (Less Than) operator.
