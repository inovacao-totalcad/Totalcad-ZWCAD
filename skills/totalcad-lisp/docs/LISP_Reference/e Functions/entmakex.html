entmakex

(entmakex [elist])

Creates a new entity or object in the drawing database, assigns it a unique handle and entity name, then returns the entity name upon success.

The elist argument specifies the entity's properties through a definition list. Mandatory fields must be included to validate the entity; omitting them results in a nil return and creation failure. Optional fields (e.g., layer, color) will use current defaults if unspecified. The function returns nil if entity generation fails due to invalid or incomplete data.

Newly created entities require ownership for persistence in DWG/DXF formats. Use functions like dictadd to assign the entity to a dictionary or other ownership structures after creation. Unowned entities exist temporarily but won’t save to disk.

Examples

Code Result
(entmakex '((0 . "LINE")(62 . 3)(10 4.0 4.0 0.0)(11 1.0 1.0 0.0))) <Entity name: 64ca670 >
