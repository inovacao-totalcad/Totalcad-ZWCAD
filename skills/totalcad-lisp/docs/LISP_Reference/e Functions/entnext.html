entnext

(entnext [entity-name])

Retrieves the subsequent entity within the drawing database.

When called without arguments, this function returns the initial undeleted entity in the drawing sequence. When provided with an entity identifier, it outputs the immediately following valid entity in the database order. Returns nil upon reaching the end of entity records or when no subsequent entities exist.

Examples

Code Result
(setq ent1(entnext )) <ENTITY NAME: 48158b00>
(setq ent2(entnext ent1)) <ENTITY NAME: 48158b00> (Entity following ent1)
