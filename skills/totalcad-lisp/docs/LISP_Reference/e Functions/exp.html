exp

(exp num)

Computes Euler's constant raised to the specified power.

This function calculates e (approximately 2.71828) multiplied by itself num times, equivalent to the exponential function enum. The output is always represented as a floating-point value, even for integer inputs. This operation serves as the reverse of the natural logarithm function.

Examples

Code Result
(exp 4) 54.5982
(exp -5) 0.00673795
(exp 1) 1.00000
(exp 4.8) 121.510
