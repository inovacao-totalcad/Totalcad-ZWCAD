fill_image

(fill_image x y width height color)

Applies a solid color fill to a specified rectangular area within a dialog box.

This operation requires placement between start_image and end_image function calls to define the active image boundaries. Coordinates (x,y) define the top-left anchor point, with width and height determining the rectangle's dimensions from the starting position (both values must be positive integers).

When using dimensions acquired through dimx_tile and dimy_tile functions, note that the coordinate system originates at the top-left corner with (0,0) as the base reference point.

Color specification accepts standard ZWCAD color indices or special logical codes:

  • -2: Active workspace background
  • -15: Dialog panel base color
  • -16: Primary foreground color
  • -18: Border accent color

Examples

Code Result
(fill_image 0 0 25 25 -15) nil
