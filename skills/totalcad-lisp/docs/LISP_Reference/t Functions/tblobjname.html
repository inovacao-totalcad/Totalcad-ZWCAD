tblobjname

(tblobjname table-name symbol)

Retrieve the entity name linked to a specific symbol in a symbol table.

This function identifies the entity name corresponding to a given symbol within a specified symbol table. By providing the symbol table name and the symbol, tblobjname locates and returns the associated entity name. Supported symbol table names include:

Table-name Meaning
"appid" Application identification.
"block" Block names.
"dimstyle" Dimension style names.
"layer" Layer names.
"ltype" Linetype names.
"style" Text style names.
"ucs" UCS names.
"view" View names.
"vport" Viewport names.

Standard symbol names by default are:

Symbol Meaning
"CONTINUOUS" Default linetype.
"0" Default layer.
"STANDARD" Default text style.
"STANDARD" Default dimension style.

Examples

Code Result
(tblobjname "style" "standard") <Entity name: 6525520 >
(tblobjname "layer" "0") <Entity name: 6525270 >
