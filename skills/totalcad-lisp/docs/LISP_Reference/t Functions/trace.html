trace

(trace function . . .)

Enables debugging mode for specified functions.

This diagnostic tool monitors the execution of designated functions. When active, it displays real-time output showing entered parameters and computed results during each function call.

Important

The tracing feature can be disabled using the untrace command. Multiple functions may be untraced simultaneously by listing them after the command.

Examples

Code Result
(defun fun (a b) (+ a b))
(trace fun)
(fun 3 4) 		Entering FUN: 3 4
Result: 7
7
