if

(if test then-expr [else-expr])

Conditionally evaluates expressions based on test result.

This control structure evaluates the test condition: if non-nil, processes then-expr and returns its value; otherwise processes the optional else-expr and returns its result. When else-expr is omitted and test fails, the function returns nil.

Examples

Code Result
(if (= 100 (abs -100)) "ok") "ok"
(if (= 12 (* 2 6)) "yes") "yes"
(if (= 17 (* 2 6)) "yes") nil
