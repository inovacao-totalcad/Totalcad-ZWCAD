acad-push-dbmod

(acad-push-dbmod)

Saves the current state of the DBMOD system variable for later restoration.

This function consistently returns a value of T.

For temporary drawing modifications, pair this function with acad-pop-dbmod – execute it before making changes and conclude with the complementary pop operation to maintain document integrity.

Related Operations
