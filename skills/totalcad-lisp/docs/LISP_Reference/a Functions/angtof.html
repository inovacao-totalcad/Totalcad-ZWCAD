angtof

(angtof str_val [unit_mode])

Converts angular string representations to floating-point radians.

Transforms a formatted angular measurement string into a radian value. The unit_mode parameter specifies the angular format convention:

Mode Input Pattern
0 Decimal degrees (DD.DDD)
1 Degrees-minutes-seconds (DD MM'SS")
2 Gradians (400g circle)
3 Radians
4 Surveyor bearings (N/S...d E/W)

Conversion will terminate with error if the input string contains invalid angular notation.

Examples

Code Result
(angtof "89") 1.55334
(angtof "44" 3) 0.0177028
(angtof "73" 2) 1.14668

Note

  • The backslash denotes that there is a quote within the string. When LISP sees the second quote, it knows this is the end of the string.

  • The angtof function is the opposite of the angtos function.
