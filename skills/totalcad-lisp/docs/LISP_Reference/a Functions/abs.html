abs

(abs number)

Returns the non-negative value of a number, ignoring its sign.

Calculates the magnitude of the specified numerical input (supports both real and integer values). Accepts a single parameter.

Examples

Code Result
(abs 0) 0
(abs -12) 12
(abs 7) 7

Note

Apply this function to transform negative numeric values into positive or validate that a number is non-negative.

To convert a number to its negative equivalent, first obtain the absolute value, then subtract this value from zero.
