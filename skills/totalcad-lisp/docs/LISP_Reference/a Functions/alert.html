alert

(alert string)

Shows a modal dialog containing a message to the user.

The function presents your specified string in a message box with an OK confirmation button. For multi-line formatting, insert newline escape sequences (\n) within the message string to create paragraph breaks.

Examples

Code Result
(alert "ZWCAD2025") ZWCAD2025
(alert "Welcome") Welcome

Note

To ensure compatibility with 640x480 screen resolutions, design dialog boxes with succinct alert messages and minimal text.
