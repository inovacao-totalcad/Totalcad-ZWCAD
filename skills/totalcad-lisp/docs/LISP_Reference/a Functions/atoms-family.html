atoms-family

(atoms-family format [symbol1 symbol2 ...])

This function retrieves a list of both built-in and custom-defined functions available in the current environment. The format parameter determines the output format of the returned data, accepting integer values 0 or 1.

Format Value Output Type
0 Returns function symbols as atomic identifiers
1 Returns function names as string values

When providing optional symbol arguments (as string entries), the function checks if the specified symbols are currently defined. Defined symbols will be returned in the requested format (atomic identifier or string), while undefined entries will appear as nil in the result list.

Examples

Code Result
(atoms-family 0 '("PLOTTERMANAGER" "LSNEW" "xyz")) (PLOTTERMANAGER LSNEW nil)
(atoms-family 1 '("BLOCK" "REDRAW" "CDR")) ("BLOCK" "REDRAW" "CDR")
