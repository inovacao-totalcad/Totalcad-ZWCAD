min

(min num1 num2 ...)

Returns the minimum value from a set of numerical inputs.

The function evaluates all given arguments and selects the lowest numerical value. If all input values are integers, the output will be an integer. When decimal values or mixed types are present, the result is returned as a real number.

Examples

Code Result
(min 45 98) 45
(min 45 -98) -98
(min 2.4 4.9) 2.40000
