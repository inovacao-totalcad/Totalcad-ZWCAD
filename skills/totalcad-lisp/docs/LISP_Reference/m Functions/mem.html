mem

(mem)

Returns current memory utilization statistics for the LISP environment.

This function outputs diagnostic information about LISP memory management. The metrics shown represent:

Parameter Description
Nodes Current count of allocated memory units for LISP operations.
Available Nodes reclaimed through memory cleanup processes.
Segments Active memory blocks reserved by the interpreter.
Block Size Memory capacity per allocated segment.
GC Cycles Total memory optimization operations executed.
