nth

(nth index collection)

Retrieves a specified element from a sequence based on its position.

Parameters

index

Zero-based numerical position to access (e.g., 0 for first element).

collection

An ordered set of elements.

This function enables direct positional access to elements, offering improved efficiency over iterative methods for extended datasets. The index value must be a non-negative integer, with the initial element residing at position 0. Returns null when the index exceeds the highest valid position in the collection.

For nested structures, nth accesses only top-level elements. Combined with list manipulation functions, it facilitates advanced data extraction patterns in LISP workflows.

Examples

Code Result
(nth 0 '(12 34 89)) 12
(nth 2 '("one" "two" "three")) "three"
