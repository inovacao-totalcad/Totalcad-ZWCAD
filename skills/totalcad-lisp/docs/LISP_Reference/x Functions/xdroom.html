xdroom

(xdroom entity-name)

Calculates remaining extended entity data (XDATA) capacity for specified objects.

This command returns the available storage space within the entity referenced by entity-name. ZWCAD entities maintain a fixed allocation of 16,383 bytes (approximately 16KB) for custom information storage. The function outputs the unused portion of this reserved memory area for attaching additional metadata.

Examples

Code Result
(command "line" '(15 14) '(19 17) "")
(setq ent (entlast))
(xdroom ent) 		16383
