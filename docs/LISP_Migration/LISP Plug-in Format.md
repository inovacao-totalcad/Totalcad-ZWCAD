## Introduction

                    

ZWCAD supports loading LISP programs in multiple formats (LSP, ZELX, VLS, FAS, VLX). This page provides an introduction to these formats.

                    
---

                    

## LSP

                    

LSP files are LISP language source code files stored in text format. They can be edited using Notepad or other text editors. These files typically contain a series of commands, functions, and logic to execute specific tasks in CAD.

                    
---

                    

## ZELX

                    

ZELX is a compiled file format for secondary development, primarily used to protect the source code of LISP programs from direct viewing or modification while improving runtime efficiency. ZELX files can be generated in ZWCAD by compiling LSP files using the COMPILE command. For detailed steps, refer to the [LISP Encryption](LISP%20Encryption.md) page.

                    
---

                    

## FAS

                    

FAS files are binary files compiled from LSP files by AutoCAD, offering higher execution efficiency and source code protection.

                    
---

                    

## VLX

                    

VLX files are binary program files generated by AutoCAD, integrating FAS, DCL, and TXT resources for user convenience.

                    
---

                    

## VLS

                    

VLS is a file format converted from VLX using third-party converters and can be loaded in ZWCAD.
