## Operating System

                    

It is recommended to use Windows OS (10 (1703) or later versions) for development and migration with ZWCAD 2026.

                    
---

                    

## Development Environment

                    

Visual Studio Code is recommended for secondary development.
                        If Visual Studio Code is not installed on your computer, launch ZWCAD and enter the VLIDE command. Follow the prompts to install Visual Studio Code and the ZwLisp Debugger, which will automatically launch Visual Studio Code.
                        You can also manually install Visual Studio Code, then search for "ZWLISP" in the Extensions Marketplace and install the plugin shown below.

                    

                    
---

                    

## Legacy Version Compatibility

                    

ZWCAD 2026 is compatible with LISP programs developed on legacy versions.
