listp

(listp element)

Checks if the specified element is a list data type.

This function verifies the list structure of an input element. It returns T when the element meets list criteria, and nil for non-list values including atomic entities and improper structures.

Examples

Code Result
(listp '("aa" "nn" "vv" )) T
(listp "str") nil
