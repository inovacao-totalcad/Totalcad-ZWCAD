lsplicencse

(lsplicencse vernumparameter)

Determines whether the user had been authorized the ZWCAD encryption for the ZWCAD software.

This function returns T if your computer installs the encryption lock for the ZWCAD. Otherwise, returns nil.

The vernumparameter specified the type of the ZWCAD vernum:

vernumparameter meaning
"ZWCAD_SINGLE" Standard in stand-alone version
"ZWCAD_PRO_SINGLE" Professional in stand-alone version
"ZWCAD_EDU_SINGLE" Educational in stand-alone version
"JIANZHU_SINGLE" Construct in stand-alone version
"JIXIE_SINGLE" Mechanical in stand-alone version
"JIEGOU_SINGLE" Struct in stand-alone version
"JIPAISHUI_SINGLE" Drainage in stand-alone version
"NUANTONG_SINGLE" Ventilation in stand-alone version
"DIANQI_SINGLE" Electrical in stand-alone version
"TSDCAD_SING" Stamping_mould in stand-alone version
"TSDMOLD_SINGLE" Plastic_mould in stand-alone version
"ZWCAD" Standard in online version
"ZWCAD_PRO" Professional in online version
"ZWCAD_EDU" Educational in online version
"JIANZHU" Constuct in online version
"JIXIE" Mechanical in online version
"JIEGOU" Construct in online version
"JIPAISHUI" Drainage in online version
"NUANTON" Ventilation in online version
"DIANQI" Electrical in online version
"ZWCAD_HS2D" High school of 2D in online version
"ZWCAD_HS3D" High school of 3D in online version
"ZWCAD_HS_TEACHING" High school teaching in online version
"ZWCAD_HS_STRUCT" High school struct in online version
"TSDCAD" Stamping_mould in online version
"TSDMOLD" Plastic_mouldl in online version
