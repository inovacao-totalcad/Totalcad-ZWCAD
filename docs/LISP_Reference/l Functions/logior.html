logior

(logior integer1 integer2 ...)

Computes the bitwise logical OR of given integers.

This function performs a bitwise OR operation across corresponding bits of input values. Each bit position in the result is set to 1 if at least one of the corresponding bits in the input integers is 1. Bits are represented as 1 (enabled) or 0 (disabled), with the operation applied sequentially to all argument pairs. The final value combines all enabled bits from any input.

Examples

Code Result
(logior 2 13 34) 47
(logior 8 2 19) 27
