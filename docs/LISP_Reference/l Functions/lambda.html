lambda

(lambda arguments expression ...)

Defines an anonymous LISP function for temporary use.

This operator dynamically generates lightweight functions without formal declaration. It's particularly useful for inline operations where full function definitions would be cumbersome. Lambda expressions are commonly embedded within parent functions and paired with list-processing routines like apply or mapcar to transform or evaluate list elements.

Examples

Code Result
(apply '((lambda (x y z)(* x (- y z)))'(5 20 14)) 30
