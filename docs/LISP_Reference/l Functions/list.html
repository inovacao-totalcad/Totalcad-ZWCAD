list

(list element ...)

Constructs a sequential data structure from specified elements.

This function assembles multiple values into a single list object. While the quote operator (') provides static list creation, the list function enables dynamic construction during execution. The returned structure can be used for parameter grouping, iterative operations, or nested data storage. For example:

(setq coordinates (list 2.4 5.7 0.0))

Multiple data types can be combined: (list "ID" 42 '('a 'b))

Examples

代码 返回值
(list "ABC" "DEF") ("ABC" "DEF")
(list 1 2.0) (1 2.0)
