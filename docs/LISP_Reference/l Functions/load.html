load

(load filename [status-msg])

Loads and compiles LISP routines into active workspace.

ZWCAD requires LISP files to be explicitly loaded for execution. Parentheses must encapsulate the load statement to differentiate it from legacy script loading operations.

Specify the target file using the filename parameter without requiring .lsp extension. Full path specification is supported; when omitted, ZWCAD scans all directories in the current LISP loading path configuration.

Successful loading returns the final evaluated expression from the file. Unsuccessful attempts generate standard file-not-found diagnostics in the command interface.

The optional status-msg parameter enables customization of success/failure notifications through user-defined string returns.

Examples

Code Result
(load "invalid") Load failed error
(load "valid") LST-FUNCT
