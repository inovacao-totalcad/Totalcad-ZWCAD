xdsize

(xdsize lst)

Calculates the byte capacity required for extended entity data storage.

This function computes the memory allocation (in bytes) needed to store extended entity data from a specified list. The lst parameter must be an XData list containing an application identifier registered via the regapp command. The calculation accounts for all XData groupings and type specifications within the provided list structure.

Examples

Code Result
(setq list_xdata (regapp "xdata_side"))
(xdsize '(-3 ("xdata_side" (1000 . "DATA")
(1002 . "{")
(1040 . 0.0)
(1040 . 1.0)
(1002 . "}")))
) 		31
