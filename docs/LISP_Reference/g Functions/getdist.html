getdist

(getdist [point] [prompt])

Prompts the user to determine a distance by entering a numerical value or selecting two points.

This function enables the user to specify a distance either through keyboard input or by picking two locations in the drawing. The returned value is always a real number, unaffected by the measurement units set in the Units dialog. An optional prompt can display instructions to the user. Input responses are restricted to numerical values or point selections; LISP expressions are not permitted.

Examples

The examples in this section demonstrate the two ways to use the getdist function.

  • Two-point method: leave out the point argument. The getpoint function prompts the user for two points. The prompt for the first point is specified by prompt;

    ZWCAD prompts, "Second point:" for the second pick point. A guide line stretches from the first point to the target to visually help in picking the second point.

    Code Result
    (getdist ) input:1,2
    input:3,4
    2.82843

  • One-point method: include the point argument. The getpoint function prompts the user for one point. The prompt for the second point is specified by prompt. A guide line stretches from the first point to the target to visually help in picking the second point.

    • Code Result
    (getdist '(3.0 2.0) "Input a distance: ")) Input a distance:4,5
    2.82843
