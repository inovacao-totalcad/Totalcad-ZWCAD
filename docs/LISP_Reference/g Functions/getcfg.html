getcfg

(getcfg param)

Retrieves configuration data for specified parameters.

This function accesses platform registry information. The input param should follow this structured path format:

"AppData/application/section/key" where:

Path Component Description
AppData Root configuration category
application Name of the target program
section Configuration subgroup identifier
key Specific value to retrieve

Examples

Code
(getcfg "AppData/application/section/key")
