getstring

(getstring [flag] [prompt])

Prompts the user for textual input and returns the provided value.

This function waits for keyboard input and captures alphanumeric characters. The returned string is limited to the initial 2048 characters entered.

When the optional flag parameter is specified with a non-nil value (commonly T), spacebar characters will be included in the input stream until the Enter key terminates input. If the flag is omitted or nil, input terminates upon encountering either the spacebar or Enter key.

Input is captured as raw text without evaluation, preventing users from entering executable LISP expressions through this function.

Examples

Code Result
(getstring "Where are you from?") Where are you from?china
"china"

Note

To prompt the user to choose from a set of predetermined keywords, utilize the getkword function instead.
