grtext

(grtext [flag text])

Displays custom content in the application's status area.

Controls text output to either the main status bar or dynamic coordinate display. The numerical flag specifies the target location:

Flag Display Area
-1 Primary status bar
-2 Live coordinate tracker

Accepts string input which will be clipped if exceeding available space. Maximum visibility duration depends on system settings and user interactions.

Note: When coordinate tracking (Coords 1/2) is active, movement inputs will automatically refresh the -2 flagged area with current positional data.

Calling the function without parameters resets both display areas to their default states, removing any user-defined text.

Examples

Code Result
(grtext -1 "tool") "tool"
