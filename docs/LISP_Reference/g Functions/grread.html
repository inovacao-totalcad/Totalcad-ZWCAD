grread

(grread [tracking] [options [cursor-style]])

Captures real-time input events from interactive devices.

This advanced input handler enables sequential data retrieval with customizable processing. When the tracking parameter is active (non-nil), continuous coordinate tracking captures dynamic pointer movements at high frequency.

Option Flags Configuration
Bitflag Behavior
1 Enables live coordinate streaming: returns lists containing event type and (X,Y,Z) position
2 Captures full keyboard input including special keys (F1-F12, arrows) without cursor interaction
4 Enables cursor type specification (required for cursor-style parameter)
8 Suppresses interruption alerts during input cancellation
Cursor Display Modes
Code Visual
0 Standard crosshair indicator
2 Invisible tracking (no visual feedback)
4 Rectangular selection marker
Event Identification
Input Source Return Format
Keyboard press (2 ASCII_code)
Coordinate selection (3 (X Y Z))
Mouse movement (5 (X Y Z))

Examples

Code
(defun c:test ()
(grread t 0)
