getint

(getint [prompt])

Prompts the user to enter an integer value.

This function displays a dialog requesting numeric input and returns the provided integer. An optional message can be supplied to guide user input. Acceptable values range from -2,147,483,648 through 2,147,483,647 (32-bit signed integer).
