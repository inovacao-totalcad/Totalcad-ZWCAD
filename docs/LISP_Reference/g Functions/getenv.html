getenv

(getenv variable)

Retrieve the value of a system environment variable.

This function queries the specified environment setting from the operating system, such as retrieving directory paths or user configurations. When the variable exists, a string containing its value is returned. Unavailable variables will return a nil value.

Examples

Code Result
(getenv "lib") "C:\\Program Files\\Microsoft Visual Studio .NET 2003\\SDK\\v1.1\\Lib\\"
(getenv "tmp") "C:\\DOCUME~1\\ADMINI~1\\LOCALS~1\\Temp"
