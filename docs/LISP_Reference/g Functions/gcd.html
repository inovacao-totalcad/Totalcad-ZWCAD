gcd

(gcd integer1 integer2)

Compute the greatest common denominator of two integers.

This function returns the largest positive integer that divides integer1 and integer2 without a remainder. Both arguments must be integer values. When working with non-integer values, apply the fix function to convert real numbers to integers before use.

Examples

Code Result
(gcd 39 45) 3
(gcd 40 45) 5
