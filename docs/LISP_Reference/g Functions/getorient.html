getorient

(getorient [base_point] [message])

Captures angular input from the user interface.

Similar to getangle but returns angular values unaffected by system variables. The measurement originates from the positive X-axis (0 radians) with counterclockwise progression, providing consistent orientation references. Returned values represent radians relative to the coordinate system's absolute basis.

Recommended for establishing canonical directions rather than incremental rotations. Input methods supporting relative coordinates (@delta) remain permissible.

Interactive responses must be graphical/coordinate inputs - symbolic expressions are disallowed.

Examples

Code Result
(getorient "Angle:") Angle:45
0.785398
