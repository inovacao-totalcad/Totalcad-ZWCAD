grdraw
(grdraw start_point end_point col_value [highlight_mode])
Creates a temporary vector graphic between specified coordinates.
This operation generates a visible connector line within the active drawing space using UCS coordinates. The start_point and end_point parameters accept either 2-dimensional or 3-dimensional coordinate lists. When segments extend beyond visible boundaries, the display intelligently truncates non-visible portions.
col_value determines the line's chromatic representation using integer codes, where -1 activates inversion rendering (XOR mode) for contrast visualization and self-erasure capabilities.
The highlight_mode parameter optionally controls emphasis display when supplied with non-zero integer values. Omission or zero value results in standard vector presentation without special highlighting effects.

Examples

Code Result
(grdraw '(2 6) '(3 8) 256 1) nil
