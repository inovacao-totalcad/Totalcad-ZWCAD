boole

(boole function int1 int2 ...)

Executes a bitwise Boolean operation using a function code.

The function parameter accepts integers 0-15, encoding 16 possible two-variable Boolean operations. Corresponding bits from input integers are processed according to the selected function.

Bit result values are determined as follows:

Bit1 Bit2 Weight
1 1 1
1 0 2
0 1 4
0 0 8

Common function codes and their effects:

Code Logic Condition
1 AND Both bits set
6 XOR One bit differs
7 OR At least one bit set
8 NOR No bits set

Examples

Code Result
(boole 1 2 3) 2
(boole 6 9 7) 14
(boole 8 8 9) -10
