*error*

(*error* string)

Handles program exception reporting and recovery mechanisms.

This user-definable function processes runtime anomalies in ZWCAD LISP applications. Developers can intercept execution faults through argument string analysis, implement corrective actions, and restore application states. For effective error management, store the initial *error* handler reference before redefinition:

(setq prev_error *error*)

Restore the original handler after critical operations using:

(setq *error* prev_error)

The function requires strict parameter compliance - a single string argument representing the error descriptor. Implement resource cleanup procedures within custom handlers to prevent memory leaks and ensure drawing file integrity.
