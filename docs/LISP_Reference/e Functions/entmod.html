entmod

(entmod entity-list)

Updates the specified entity within the current DWG file.

This operation applies alterations to a database entity through modified association lists. After editing data obtained via entget, entmod permanently commits these changes to the drawing registry while maintaining entity hierarchy and handle consistency.

Examples

Code Result
(command "circle" '(5 11) 5)
(setq ent (entlast))
(setq ed (entget ent))
(setq ed(subst (cons 40 20)(assoc 40 ed) ed))
