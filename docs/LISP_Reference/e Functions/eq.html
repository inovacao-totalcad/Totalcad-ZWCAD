eq

(eq expr1 expr2)

Evaluates whether two expressions reference identical symbols in memory.

Returns T if both expressions point to the same symbol object, otherwise returns nil. This operator tests for strict symbol identity rather than value equivalence.

Examples

Code Result
(setqs1 '(1 2 3))
(setqs2 '(1 2 3))
(setqs3s2)
(eq s1s3)
 nil
(eq s2s3) T

Note

The **eq** function differs from both the **=** (equality operator) and **equal** (expression equivalence function). The **=** operator checks if numeric or string values are identical. The **equal** function verifies whether two expressions are structurally equivalent, optionally considering a specified tolerance. **eq**, however, evaluates to **T** only if two expressions reference the exact same symbol or object in memory.
