entlast

(entlast)

Returns the most recently created entity in the drawing.

This function accesses the newest non-deleted database record, ideal for operations requiring immediate use of the latest drawn object.

Examples

Code Result
(command "line" '(2 3) '(6 9) "")
(entlast ) 		<Entity name: 49d2bf0 >

Note

  • The entity does not need to be currently on screen, unthawed, or unlocked to be selected. This behavior differs from the Last selection set option.

  • To find the first entity in the database, use the entnext function with no arguments.
