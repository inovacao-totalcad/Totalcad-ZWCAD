entget

(entget entity-name [application-list])

Retrieves the DXF group codes and values of a specified entity.

This function accesses the drawing database to return an entity's property list in LISP format. Developers typically store this list in a variable and manipulate it using list processing functions such as car, cdr, and assoc to extract specific parameters.

The output consists of structured group code-data pairs formatted as dotted pairs. Each group code (integer) corresponds to specific entity attributes, with its subsequent element containing the associated value for that attribute.

Examples

Code Result
(command "line" '(2 3) '(6 9) "")
(entget (entlast)) 		((-1 . ) (0 . "LINE") (5 . "E3") (67 . 0) (8 . "0") (410 . "Model") (62 . 256) (6 . "ByLayer") (370 . -1) (48 . 1.00000) (60 . 0) (39 . 0.000000) (10 2.00000 3.00000 0.000000) (11 6.00000 9.00000 0.000000) (210 0.000000 0.000000 1.00000))

Note

  • Entget does not return all information about an entity. Missing is dotted pair data about the entity's properties when they do not differ from default values: color, linetype, thickness, attributes-follow flag, and the entity handle.

  • While the data returned by entget is very similar to DXF format, there is one primary difference: x,y,z coordinates are returned by entget as a single value, rather than the separate values in DXF. Thus, you only see group code 10 with entget, instead of DXF group codes 10 (x-coordinate), 20 (y-coordinate), and 30 (z-coordinate).
