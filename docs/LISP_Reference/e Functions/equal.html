equal
(equal statement1 statement2 [tolerance])

Evaluates if two statements are identical.

This function performs a comparison between statement1 and statement2, returning T if they match exactly and nil otherwise. While the equal function operates on lists, the = operator is designated for numerical and string comparisons. When comparing floating-point values, the optional tolerance parameter specifies the permissible difference threshold.

Note

The equal function operates differently from the = operator and eq. The = operator evaluates to T when numeric or string values match, while equal returns T if two expressions have equivalent structural contents. The eq function checks identity, yielding T only when two expressions reference the same memory object.
