entupd
(entupd entity-name)
Forces a graphical refresh of modified entities.
When editing nested elements like block attributes or polyline vertices, visual updates are deferred to enhance performance. This function manually triggers a regeneration of complex entities after making modifications.
Providing the entity-name of any sub-component within a block definition or polyline structure will refresh the entire parent entity's display representation in the drawing space.

Examples

Code Result
(command "circle" '(5 11) 5)
(setq ent (entlast))
(setq ed (entget ent))
(setq ed(subst (cons 40 20)(assoc 40 ed) ed))
(entmod ed)
(entupd ent)
 <Entity name: 64c5380 >

Note

Use the (command "regen") function to refresh all displayed entities on the screen.
