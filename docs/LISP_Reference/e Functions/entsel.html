entsel

(entsel [message])

Prompts the user to interactively pick a graphical object.

This core functionality returns an association list containing both the entity's identifier and the XYZ coordinates of the selection point. Prior object snap configurations are temporarily overridden unless explicitly invoked during selection.

When a message argument is specified, it replaces the standard "Select Object:" prompt. If omitted, the operation uses default prompting text. This function is commonly used in scenarios requiring precise element selection with coordinate capture.

Examples

Code Result
(command "line" '(2 3) '(6 9) "")
(entsel"Select Entity:" ) 		(<Entity name: 64c7df0> (2.00000 3.00000 0.000000))

Note

The entsel function is limited to top-level entities. For selecting sub-entities nested within blocks or polylines, utilize nentsel.
