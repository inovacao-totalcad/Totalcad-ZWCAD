acad_strlsort

(acad_strlsortlst)

Alphabetically sorts a sequence of string elements.

This function organizes string collections in ascending lexicographical order. The input must be a quoted string list generated through standard LISP notation, such as '( "item1" "item2" ). Case sensitivity follows the current system locale settings.

Examples

Code Result
(acad_strlsort "one" "two" "three") ("one" "three" "two")
(acad_strlsort "c" "d" "b" "a") ("a" "b" "c" "d")

Note

The apostrophe (') in LISP acts as the quote operator, which suppresses evaluation of an expression by treating it as data rather than executable code.
