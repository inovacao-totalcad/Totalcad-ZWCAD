acad_colordlg

(acad_colordlg clr_index [options])

Launches the color selection dialog interface.

This routine opens the standard color picker and returns the numerical index of the chosen color. Returns nil if operation is canceled.

Parameters
Parameter Description Sample Valid Input
clr_index Preselected color identifier 62 0 (BYBLOCK) - 256 (BYLAYER)
options Control special color modes t Non-nil: Enable all options
Nil: Hide BY* selections

Implementation Details:

  • Passing 256 as clr_index preselects the active layer's color (BYLAYER)
  • When options parameter is omitted or non-nil, both BYBLOCK and BYLAYER choices remain accessible
  • Setting clr_index to 1-255 selects corresponding ACI colors

Examples

Code Result
(acad_colordlg 5) Displays dialog box with default value 5 (blue).
(acad_colordlg 5 nil) Displays dialog box with default value 5 (blue), without BYBLOCK and BYLAYER buttons.

Note

In ZWCAD's LISP functions, the initial eight color indices are assigned as follows:

Number Color
1 Red
2 Yellow
3 Green
4 Cyan (light blue)
5 Blue
6 Magenta (pink)
7 White
8 Gray
