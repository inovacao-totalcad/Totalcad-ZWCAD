acad_truecolordlg

(zwcad_truecolordlg base-color [mode-enable])

Activates the color selection interface with multiple palette options.

This command opens a tri-panel color selector containing Indexed Colors, RGB Values, and Color Swatch Book sections. Returns the chosen color specification or nil if canceled by the user.

The base-color parameter sets the initial active tab and selection:

  • 62-type integer (0-256): Activates indexed colors. Special values: 0=BYBLOCK, 256=BYLAYER
  • 420-type integer: Activates RGB mode using COLORREF encoding
  • 430-type string (color$book format): Activates color book references

When mode-enable is set to false, organizational color modes (BYBLOCK/BYLAYER) become unavailable.

Output consists of group code pairs representing the selection:

  • Index selection: Single (62 . index) pair
  • RGB selection: Two pairs - nearest index (62) and RGB value (420)
  • Swatch selection: Three pairs - index (62), RGB (420), and book reference (430)
The interface preserves color equivalencies between selection methods when possible.
