autoload
(autoload application list)
Enables automatic loading of LISP applications upon command activation.
This function establishes a linkage between specified command triggers and an application identifier. When executing any registered command, ZWCAD dynamically locates and loads the corresponding LISP program file for on-demand functionality.

Examples

Code
(autoload "example" '("test1" "test2"))

Note

  • ZWCAD loads the example.lsp.
  • Test1 and Test2 are command name by user define.
