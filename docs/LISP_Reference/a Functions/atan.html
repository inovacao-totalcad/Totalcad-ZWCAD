atan

(atan number1 [number2])

Computes the inverse tangent (arctangent) value.

This function determines the principal arctangent of the ratio between number1 and number2. When the second argument is omitted, number2 defaults to 1.0, effectively calculating the arctangent of number1. The resulting angle is expressed in radians and lies within the range of -π/2 to π/2.

Examples

Code Result
(atan 8) 1.44644
(atan 9.6) 1.46700
(atan -4) -1.32582
