add_list

(add_list string)

Inserts or modifies a text element within an active dialog component.

This operation updates list content in dialog boxes initialized with start_list. The preceding start_list call defines:

  • Target position for the string modification

  • Interaction mode (append or overwrite)

Examples

Code
(setq tmp '("china"))
(start_list "DCL")
(add_list tmp)
(end_list)

Note

This function is employed in designing list boxes or drop-down lists within DCL interfaces. Practical implementation examples can be found in the documentation for list_box and popup_list components.
