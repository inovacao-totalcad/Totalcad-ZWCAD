atoi

(atoi string)

Transforms a numeric string into its integer equivalent.

The atoi function parses the input string and returns its integer representation. Decimal values are truncated without rounding. If the provided string contains non-numeric characters or is improperly formatted, the function will return a value of 0.

Examples

Code Result
(atoi "7.9") 7
(atoi "-9.3") -9
(atoi "a") 0
