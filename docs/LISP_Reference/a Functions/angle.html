angle

(angle point1 point2)

Calculate the angle formed by two specified points.

Computes the angle from point1 to point2 within the current UCS. Point1 establishes the reference axis aligned with the UCS X-axis. The measured angle between the constructed line (point1 to point2) and the reference axis is output in radians.

Examples

Code Result
(angle '(8 9) '(3 8)) 3.33899
(angle '(4 8.7 6) '(5 8 9)) 5.67246
(angle '(0 0) '(0 0)) 0.000000

Note

  • This function is different from the getangle function. Getangle prompts the user to select two points defining an angle.
