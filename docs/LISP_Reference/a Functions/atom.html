atom

(atom item)

Checks if an element is an atomic entity in LISP.

An atomic element refers to any data type that does not contain a cons structure. This function returns T for numbers, symbols, strings, and other non-list values. If the input is a list or dotted pair structure, nil will be returned instead.

Examples

Code Result
(atom 's) T
(atom 3) T
(atom '(x y z)) nil
