and

(and expression ...)

Performs Boolean conjunction evaluation.

This function evaluates multiple expressions sequentially, returning nil immediately upon encountering a false value. If all expressions evaluate to non-nil (including the last expression's value), it returns the result of the final expression. The evaluation short-circuits once any nil result is detected.

Examples

Code Result
(and 3.9 nil) nil
(and 3.9 "hello" 0) T
(and 2 -5) T
(and 8.7) T
(and) T
