alloc

(alloc integer)

Configures the memory allocation units for LISP environments.

Specifies the quantity of memory segments (measured in allocation units) reserved for LISP processes via an integer parameter. Returns the prior allocated memory value, demonstrated in subsequent usage examples.

Examples

Code Result
(alloc 234) 514
(alloc 28) 234
(alloc 65) 28
