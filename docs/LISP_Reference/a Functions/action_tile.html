action_tile

(action_tile key expression)

Defines a callback handler for dialog tile interactions.

Assigns a LISP expression to execute when the specified tile identified by case-sensitive key receives user input. The expression may access contextual arguments during execution. Applies to interactive elements like toggle buttons, action buttons, and selection controls within dialog interfaces.

The handler expression can utilize these predefined variables:

Argument Description
$value State/content of tile at event trigger
$key Identifier of activated tile
$data Developer-defined metadata
$reason Event context identifier
$x Horizontal position for image tiles
$y Vertical position for image tiles

Examples

Code Result
(action_tile "K_1" "(print $value)") nil

Note

  • The expression assigned by action_tile overrules the default action of the dialog box (which is assigned via the new_dialog function) and the tile's action attribute.

  • The command function cannot be called by action_tile.
