acad_helpdlg

(acad_helpdlghelpfile [topic])

Invokes the ZWCAD Help dialog interface.

This function activates the assistance panel for the specified documentation. The helpfile parameter accepts a file path or name (supports .chm and .hlp formats). When provided, the optional topic parameter navigates to a specific subject entry. If no topic is specified, the main index page of the help file is displayed. Returns T upon successful content display or nil if the system cannot locate the requested resource.

Examples

Code Result
(acad_helpdlg "ZwHelp.exe" "") Displays dialog box with "ZwHelp.exe"
