acad_truecolorcli

(acad_truecolorcli color [allowbylayer] [prompt])

Interactive color selection function for command-line interface.

This routine initiates a color selection dialog at the command prompt. Returns either a list of property-value tuples defining the chosen color or nil if aborted.

color: Preset color specification. Accepts integer color indices or DXF-formatted pairs (62, 420, or 430 groups):

  • (62 . N): Integer index (0=BYKBLOCK, 256=BYKLAYER)
  • (420 . RGB): 24-bit true color value
  • (430 . "Name$Catalog"): Color book reference

allowbylayer: When present/non-nil, enables BYLAYER/BYBLOCK selection

prompt: Custom prompt message (default: standard color query)

Output formats vary by selection type:

  • Index color: Single (62 . Index) tuple
  • True color: Two tuples - nearest index (62) and RGB value (420)
  • Book color: Three tuples - nearest index (62), RGB equivalent (420), and catalog entry (430)
