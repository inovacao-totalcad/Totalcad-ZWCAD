atof

(atof string)

Transforms alphanumeric characters into a floating-point value.

The routine parses numerical representations within the input string and yields their corresponding real number equivalent. When encountering non-numeric sequences, the function outputs 0.0 as the default result.

Examples

Code Result
(atof "8") 8.00000
(atof "-5") -5.00000.
(atof "a") 0.000000
