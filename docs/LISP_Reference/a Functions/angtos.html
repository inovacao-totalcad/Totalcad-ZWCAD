angtos

(angtos angle [mode [precision]])

Transforms a radian angle measurement into a human-readable angular string representation, respecting system angular base settings.

The angular-to-string conversion utility supports multiple notation formats through mode specification. While sharing conceptual similarities with numerical conversion functions, this routine specifically handles angular measurement interpretations. Format options include:

Mode Format Style Sample Output
0 Degree decimal notation 142.75°
1 Sexagesimal degree format 122°15'30"
2 Gradian measurement 200.00g
3 Radial measurement 3.14r
4 Directional bearing format S 45° E

Decimal Control: The precision parameter (0-15) determines fractional display resolution when applicable.

Examples

Code Result
(angtos 0.4503) "25.783"
(angtos 0.4513) "0.45r"
(angtos 0.4533) "25d46'59\""
