foreach

(foreach variable list expression ...)

Execute specified expressions sequentially for each element in a list.

This iterator function processes all elements in the given list by assigning each element to the temporary variable. The variable parameter receives successive list values during iteration. Following parameters include the target list and one or more expressions to evaluate. All expressions execute atomically for each list element, with the final expression's result becoming the overall return value of the foreach operation.

Examples

Code Result
(setq sample '(1.0 1.5 2.0 2.5))
(foreach result(cdr sample)) 		(1.50000 2.00000 2.50000)
