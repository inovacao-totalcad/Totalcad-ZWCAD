float

(float number)

Transforms an integer into a floating-point value.

This conversion modifies the numeric type by appending a decimal separator and fractional component. Whole numbers are converted to real numbers through the addition of a decimal point followed by zero digits.

Examples

Code Result
(float 6) 6.00000
(float 8.4) 8.40000
(float -3.9) -3.90000

Note

This function inverts the operation performed by the fix function.
