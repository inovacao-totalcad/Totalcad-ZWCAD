vlax-curve-getClosestPointTo

(vlax-curve-getClosestPointTo curve-obj givenPnt [extend])

Returns the point (in WCS) on a curve or its extensions that is nearest to the specified point.

If the curve-obj argument represent a curve, this function returns the point on the curve or its extensions which is nearest to the specified point. Otherwise, returns nil.

The function accepts two essential arguments and one optional argument:

Argument Meaning
curve-obj A VLA-object.
givenPnt A list representing a point in WCS, which used to measure the closest point to this point.
extend Search the target point on the curve or its extensions.

Examples

Code Result
(vlax-curve-getClosestPointTo curve-obj '(9.3 -5.1 0)) (10.0000 0.000000 0.000000)

Return the closest point on the arc to the coordinates 9.3,-5.1.
(vlax-curve-getClosestPointTo curve-obj '(9.3 -5.1 0) T) (8.76812 -4.80833 0.000000)

Return the closest point on the arc's extensions to the coordinates 9.3,-5.1.
