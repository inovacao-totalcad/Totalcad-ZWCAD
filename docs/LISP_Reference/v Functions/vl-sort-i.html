vl-sort-i

(vl-sort-i list comparison-function)

Returns the index values of the elements of list, sorted in the order specified by give comparison function.

This function sorts the elements in a list according to a given comparison function. This function returns the element index numbers.

The compare function value can take one of the following forms:

predicate-function value
A symbol (function name)
'(LAMBDA (X Y) ...)
(FUNCTION (LAMBDA (X Y) ...))

Examples

Code Result
(vl-sort-i '(2 8 9 4) '>) (2 1 3 0)
