vlax-safearray-get-dim

(vlax-safearray-get-dim var)

Returns the number of dimensions in a safearray object.

If var doesn't represent a safearray, this function returns an error message, otherwise a integer representing the number of dimensions in var.

The function accepts one argument:

Argument Meaning
var A safearray.

Examples

Code Result
(setq var (vlax-make-safearray vlax-vbsingle '(0 . 2) '(0 . 2)))
(vlax-safearray-get-dim var) 		2
