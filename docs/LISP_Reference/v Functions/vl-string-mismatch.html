vl-string-mismatch

(vl-string-mismatch str1 str2 [pos1 pos2 ignore-case-p])

Calculates the maximum shared prefix length between two character sequences.

The function determines the greatest number of initial characters that match between specified offsets in both inputs. Positions pos1 and pos2 indicate the starting indices for comparison (omitted if set to zero). When ignore-case-p is enabled as T, letter case differences are disregarded during evaluation.

Examples

Code Result
(vl-string-mismatch "abcd" "abef") 2
(vl-string-mismatch "abcd" "sabcef" 0 1) 3
(vl-string-mismatch "abcd" "sABCef" 0 1 T) 3

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (vl-string-mismatch "abc?????abc" "abc??????")

  • When LISPSYS is 1, the result is "8".
  • When LISPSYS is 0, the result may not be as expected.
