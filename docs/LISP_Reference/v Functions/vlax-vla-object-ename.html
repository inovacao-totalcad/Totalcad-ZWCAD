vlax-vla-object->ename

(vlax-vla-object->ename obj)

Transforms a VLA-objectan to an entity .

If obj supplied is a valid ActiveX object, this function returns an autolisp's entity name, otherwise prompts "error: bad argument type".

The function accepts one argument:

Argument Meaning
obj A VLA-object.

Examples

Code Result
(setq curDoc (vlax-get-property (vlax-get-zwcad-object) 'ActiveDocument))
(setq mSpace (vlax-get-property curDoc 'ModelSpace))
(setq FirstVName (vlax-invoke-method mSpace 'Item 0))
(vlax-vla-object->ename FirstVName)
 #<Entity name: 5a01090>
