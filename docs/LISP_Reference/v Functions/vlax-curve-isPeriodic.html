vlax-curve-isPeriodic

(vlax-curve-isPeriodic curve-obj)

Determines whether the specified curve can be extended infinitely in both directions and has a period value dT.

If the curve is periodic and can be extended infinitely, this function returns T, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result 
(command "circle" "0,0" 20.0)
(setq curve-obj (vlax-ename->vla-object (entlast)))
(vlax-curve-isPeriodic curve-obj)
T

curve-obj argument represents circle, which is a periodic curve. 

(command "line" "0,0" "20.0,30.0" "")
(setq curve-obj (vlax-ename->vla-object (entlast)))
(vlax-curve-isPeriodic curve-obj)
nil

curve-obj argument represents line, which isn't a periodic curve.
