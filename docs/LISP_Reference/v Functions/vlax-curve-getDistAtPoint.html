vlax-curve-getDistAtPoint

(vlax-curve-getDistAtPoint curve-obj point)

Returns the length of the part of the curve from the curve's start point to the specified point.

If the point specified by point argument is on the curve, this function returns a real number representing the length up to the specified point, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
point A 3D point list (in WCS)

Examples

Code Result 
(vlax-curve-getDistAtPoint
  curve-obj
  (osnap (getpoint "\npick middle point: ") "_mid")
)
 12.3523
Returns the half length of the spline. 
(vlax-curve-getDistAtPoint
  curve-obj
  (osnap (getpoint "\npick middle point: ") "_non")
)
 nil
The point argument isn't a point on the curve because of closing osnap.
