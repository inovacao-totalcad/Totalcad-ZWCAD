vlax-curve-getDistAtParam

(vlax-curve-getDistAtParam curve-obj param)

Returns the length of the part of the curve from the curve's start point to the specified parameter.

If the value of param argument is between the startparam (get with vlax-curve-getStartParam function) and endparam (get with vlax-curve-getEndParam function), this function returns a real number representing the length up to the specified parameter, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
param A real number, and its available value is between startparam and endparam of the measured curve.

Examples

Code Result 
(vlax-curve-getDistAtParam
  curve-obj
  (vlax-curve-getEndParam curve-obj)
)
 24.7499
Returns the total length of the spline.
(vlax-curve-getDistAtParam curve-obj 40.2) nil
The value of param argument is more than the endparam of the curve, this expression returns nil.
