vl-directory-files

(vl-directory-files [directory pattern directories])

Retrieves a list of files and subdirectories within a specified folder path.

Returns filenames and paths as a list. Returns nil if no matches are found for the criteria.

Optional parameters:
Parameter Description
directory Path string to search. Uses current ZWCAD working directory if unspecified
pattern Wildcard filter (e.g., "*.dwg"). Defaults to "*.*" when omitted
directories Filter mode selector:
  • -1Exclude files (directories only)
  • 0Include both files and directories
  • 1Exclude directories (files only)
    • Default: 0

    Examples

    Code Result
    (vl-directory-files "C:\\WINDOWS\\Help") ("." ".." "Tours" "netcfg.hlp" "api.chm" "hhaxref.chm" "htmlref.chm" "htmlhelp.chm" "acsignext.hlp")
    (vl-directory-files "C:\\WINDOWS\\Help" nil 1) ("netcfg.hlp" "api.chm" "hhaxref.chm" "htmlref.chm" "htmlhelp.chm" "acsignext.hlp")
    (vl-directory-files "C:\\WINDOWS\\Help" "*.hlp") ("netcfg.hlp" "acsignext.hlp")

    Unicode support

    The result of this function is affected by the LISPSYS system variable.

    Example: (vl-directory-files "D:/tmp/")

    • When LISPSYS is 1, the result is "("." ".." "debug.log" "ПСМ_Карты.dwg" "?????.txt")".
    • When LISPSYS is 0, the result may not be as expected.
