vlax-curve-getSecondDeriv

(vlax-curve-getSecondDeriv curve-obj param)

Returns the second derivative (in WCS) of a curve at the specified param.

If the value of param argument is between the startparam (got with vlax-curve-getStartParam function) and endparam (got with vlax-curve-getEndParam function), this function returns a 3D point list representing the second derivative of the curve at the param, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
param A real number, and its available value is between startparam and endparam of the measured curve.

Examples

Code Result 
(vlax-curve-getSecondDeriv
  curve-obj
  (/ (-	(vlax-curve-getEndParam curve-obj)
	(vlax-curve-getStartParam curve-obj)
     )
     2.0
  )
)
 (0.000756251 0.0116285 0.000000)
Returns the second derivative of the spline at its middle point.
(vlax-curve-getSecondDeriv curve-obj 40.2) nil
The value of param argument is more than the endparam of the curve, this expression returns nil.
