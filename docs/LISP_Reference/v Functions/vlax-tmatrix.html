vlax-tmatrix

(vlax-tmatrix list)

Returns a 4 x 4 transformation matrix which can be used by tranformby VLA-method.

If the specified list's format is undesirable, this function prompts "Error: bad argument", otherwise returns a variant of type safearray, representing a 4 x 4 transformation matrix.

The function accepts one argument:

Argument Meaning
list A list containing four elements, and each element is a list containing four numbers.

Examples

Code Result
(vl-load-com)
(setq var_tmatrix (vlax-tmatrix '((10 0 0 0) (0 10 0 0) (0 0 10 0) (0 0 0 1))))
(setq arr_tmatrix (vlax-variant-value var_tmatrix))
(vlax-safearray->list arr_tmatrix) 		((10.0000 0.000000 0.000000 0.000000)
(0.000000 10.0000 0.000000 0.000000)
(0.000000 0.000000 10.0000 0.000000)
(0.000000 0.000000 0.000000 1.00000))
