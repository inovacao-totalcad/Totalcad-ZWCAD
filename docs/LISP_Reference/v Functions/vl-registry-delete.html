vl-registry-delete

(vl-registry-delete reg-key [val-name])

Deletes Windows registry key.

This function deletes Windows registry key. If the val-name is existed and is not a nil, this function deletes the specified value in the registry. If the val-name is not existed or is a nil, this function deletes the specified Windows registry key.

If this function returns a T, it is successful; otherwise this function returns a nil.

Examples

Code Result
(vl-registry-write "HKEY_CURRENT_USER\\Software\\Test")
(vl-registry-delete "HKEY_CURRENT_USER\\Software\\Test") 		T
