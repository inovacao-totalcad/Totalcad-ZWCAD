vlax-ename->vla-object

(vlax-ename->vla-object entname)

Transforms an entity to a VLA-object.

If entname supplied is a valid autolisp object's name, this function returns a VLA-object's name, otherwise displays an error message.

The function accepts one argument:

Argument Meaning
entname An autolisp object's name (returned by entget, entsel or entlast functions).

Examples

Code Result
(command "pline" "0,0" "20,30" "60,15" "70,-20" "C")
(setq ename (entlast))
(setq vla_object (vlax-ename->vla-object ename))
