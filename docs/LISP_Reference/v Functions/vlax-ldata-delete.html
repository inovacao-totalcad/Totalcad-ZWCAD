vlax-ldata-delete

(vlax-ldata-delete dict key)

Erases key from a drawing dictionary.

If the specified key exists in the specified dictionary, this function erases the key successfully and returns T, otherwise nil.

The function accepts two arguments:

Argument Meaning
dict A VLA-object(ZWCAD drawing entity object), or a string naming a global dictionary.
key A string specifying the dictionary key.

Examples

Code Result
(vl-load-com)
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Chinaweal Longteng")
(vlax-ldata-delete "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1") 		T
