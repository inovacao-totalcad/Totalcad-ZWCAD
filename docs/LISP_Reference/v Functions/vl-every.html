vl-every

(vl-every predicate-function list [list]...)

Checks whether the predicate is true for every element combination.

This function passes the first element of each supplied list as an argument to the test function, followed by the next element from each list, and so on. Evaluation stops as soon as one of the lists runs out. If predicate-function returns a non-nil value for every element combination, vl-every function returns T, otherwise nil

The function accepts two arguments at least and some other optional arguments:

Argument Meaning
predicate-function The test function. This can be any function that accepts as many arguments as there are lists provided with vl-every, and returns T on any user-specified condition. The predicate-function value can take one of the following forms:
  • A symbol (function name)
  • '(LAMBDA (A B) ...)
  • (FUNCTION (LAMBDA (A B) ...))
    • list A list to be tested

    Examples

    Code Result
    (vl-every '(lambda (fnm) (> (vl-file-size fnm) 0))
    (vl-directory-files "C:\\WINDOWS\\Help" nil 1))     		T
    (setq alist (list 1 2 3 4))
    (setq temp nil)
    (vl-every '= temp alist)     		T
