vlr-beep-reaction

(vlr-beep-reaction [args])

Produces a beep sound.

This is a predefined callback function that accepts a variable number of arguments, depending on the reactor type.

Examples

Code Result
(vl-load-com)
(vlr-acdb-reactor nil '((:vlr-objectAppended . vlr-beep-reaction)))
 Whatever you draw, these codes produce a beep sound.

Note

The function can be linked to an event-listener to assist with troubleshooting.
