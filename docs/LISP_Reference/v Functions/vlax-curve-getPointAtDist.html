vlax-curve-getPointAtDist

(vlax-curve-getPointAtDist curve-obj dist)

Returns the point along a curve at the specified distance.

If the specified distance equal to or less than the length of the curve, this function returns a 3D point list representing a point on the curve, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
dist The distance along the curve.

Examples

Code Result
(command "spline" "0,0" "6,7" "12,2" "22,8" "" "" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(command "ucs" "O" "100,100")
(vlax-curve-getPointAtDist vla_object 10.0) 		(6.26490 6.91769 0.000000)

Note

This function provides the 3D coordinates of a point in the WCS, regardless of whether the current coordinate system is set to UCS.
