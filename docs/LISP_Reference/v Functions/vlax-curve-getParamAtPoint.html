vlax-curve-getParamAtPoint

(vlax-curve-getParamAtPoint curve-obj point)

Returns the parameter of the curve at the specified point.

If the specified point is on the curve or on the extended line of the curve, this function returns a real number representing an parameter, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
point A 3D point list on curve or on the extended line of curve.

Examples

Code Result
(command "line" "0,0" "20,30" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(command "osnap" "mid")
(setq pt (getpoint "\npick a point on the line:"))
(vlax-curve-getParamAtPoint vla_object pt) 		18.0278 (the half length of the line)

Note

When the provided point lies along the curve's extension, this function may still output a real value representing its parameter.
