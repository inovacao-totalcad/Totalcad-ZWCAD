vl-string-subst

(vl-string-subst new-str pattern string [start-pos])

Substitutes a target substring in a given string with a replacement value.

The modified string is returned after performing substitutions. The operation locates occurrences of the pattern within the input string and replaces them with new-str. When start-pos is provided, the search initiates from the defined character position.

Examples

Code Result
(vl-string-subst "one" "two" "one two three") "one one three"
(vl-string-subst "two" "one" "two two three" 2) "two two three"
