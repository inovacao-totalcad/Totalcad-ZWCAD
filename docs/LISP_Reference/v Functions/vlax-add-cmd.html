vlax-add-cmd

(vlax-add-cmd global-name func-sym)

Adds custom function to ZWCAD commands set.

Generally, the custom function (function name has no "c:" prefix) can't be executed in ZWCAD command bar, but this function can define these functions as ZWCAD common command with the name of the global-name argument. If successfully, this function returns the value of global-name argument, otherwise, returns nil.

Before invoking vlax-add-cmd to add welcomeinfo function to ZWCAD command set, we can't execute welcomeinfo function in ZWCAD command bar. Now we can execute Hello command in ZWCAD command bar to invoke welcomeinfo function.

Examples

Code Result 
(defun welcomeinfo ()
  (princ "\nWelcome to use ZWCAD LISP language programming")
  (princ)
)
(vlax-add-cmd "Hello" 'welcomeinfo)
 (Input Hello in the command line. The result is)
Welcome to use ZWCAD LISP language programming

NOTE

The command added by vlax-add-cmd function can't be called transparently in command function, doing so ZWCAD will reports "error: rejected function".
