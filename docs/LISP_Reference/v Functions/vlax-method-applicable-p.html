vlax-method-applicable-p

(vlax-method-applicable-p obj method)

Determines whether an VLA object supports a specified method.

If the VLA object supports the specified method, this function returns T, otherwise nil.

The function accepts two arguments:

Argument Meaning
obj A VLA object.
method A string or symbol representing the method name to be tested.

Examples

Code Result
(vlax-method-applicable-p line-obj 'Move) T

Determines if line object supports move method.
(vlax-method-applicable-p line-obj 'Addline) nil

Determines if line object supports addline method.
