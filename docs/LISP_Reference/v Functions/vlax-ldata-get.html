vlax-ldata-get

(vlax-ldata-get dict key [default-data])

Gets LISP data from a drawing dictionary or an object.

If the specified key is existed, this function returns its data value, otherwise returns the dafault-data.

The function accepts two arguments at least and one optional argument:

Argument Meaning
dict A VLA-object(ZWCAD drawing entity object), or a string naming a global dictionary.
key A string specifying the dictionary key.
default-data If no matching key in the dictionary, or if the dictionary does not exist, return this default value.

Examples

Code Result
(vl-load-com)
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Chinaweal Longteng")
(vlax-ldata-get "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Can't get the LISP data from the specified key in the dictionary") 		"Chinaweal Longteng"
(vl-load-com)
(vlax-ldata-put "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Chinaweal Longteng")
(vlax-ldata-delete "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1")
(vlax-ldata-get "ZWCAD_BOM_DICTIONARY" "ZWCAD_MXB_MXL1" "Can't get the LISP data from the specified key in the dictionary") 		"Can't get the LISP data from the specified key in the dictionary"
