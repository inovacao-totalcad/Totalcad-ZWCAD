vlax-curve-getFirstDeriv

(vlax-curve-getFirstDeriv curve-obj param)

Returns the first derivative (in WCS) of a curve at the specified param.

If the value of param argument is between the startparam (got with vlax-curve-getStartParam function) and endparam (got with vlax-curve-getEndParam function), this function returns a 3D point list representing the first derivative of the curve at the param, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
param A real number, and its available value is between startparam and endparam of the measured curve.

Examples

Code Result 
(vlax-curve-getFirstDeriv
  curve-obj
  (/ (-	(vlax-curve-getEndParam curve-obj)
	(vlax-curve-getStartParam curve-obj)
     )
     2.0
  )
)
 (0.904500 -0.578730 0.000000)
Returns the first derivative of the spline at its middle point.
(vlax-curve-getFirstDeriv curve-obj 40.2) nil
The value of param argument is more than the endparam of the curve, this expression returns nil.
