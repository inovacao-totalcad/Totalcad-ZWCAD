vlax-put-property

(vlax-put-property obj property arg)

Sets the specified property of an ActiveX object.

If the specified property is set successfully, this function returns nil.

The function accepts three arguments:

Argument Meaning
obj A VLA-object.
property A string or symbol representing a property of the VLA-object.
arg The value to be set.

Examples

Code Result
(vl-load-com)
(setq vlaCircle (vlax-ename->vla-object (car (entsel "\nselect a circle: "))))
(vlax-put-property vlaCircle 'Color 2)
(vlax-invoke-method vlaCircle 'update) 		The seleted circle's color is changed to yellow.

Note

It is recommended to refresh the VLA-object immediately after adjusting its properties, as ZWCAD may not automatically reflect changes to certain VLA-object attributes in the drawing interface.
