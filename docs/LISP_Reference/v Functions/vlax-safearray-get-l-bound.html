vlax-safearray-get-l-bound

(vlax-safearray-get-l-bound var dim)

Returns the lower boundary of the specified dimension of an array.

If the specified var is not an array, or the specified dim is invalid, this function prompts an error message, otherwise returns an integer representing the lower boundary (starting index) of the dimension.

The function accepts two arguments:

Argument Meaning
var A safearray.
dim A integer representing the tested dimension of the array. The first dimension is dimension 1.

Examples

Code Result
(setq matrix (vlax-make-safearray vlax-vbString '(0 . 2) '(0 . 3)))
(vlax-safearray-get-l-bound matrix 1) 		0
