vlax-erased-p

(vlax-erased-p vla-obj)

Determines if an VLA-object was erased.

If vla-obj supplied was erased, this function returns T, otherwise nil.

The function accepts one argument:

Argument Meaning
vla-obj A VLA-object.

Examples

Code Result
(command "pline" "0,0" "20,30" "60,15" "70,-20" "C")
(setq vla_object (vlax-ename->vla-object (entlast)))
(vlax-erased-p vla_object)) 		nil
(command "pline" "0,0" "20,30" "60,15" "70,-20" "C")
(setq vla_object (vlax-ename->vla-object (entlast)))
(entdel (entlast))
(vlax-erased-p vla_object)) 		T
