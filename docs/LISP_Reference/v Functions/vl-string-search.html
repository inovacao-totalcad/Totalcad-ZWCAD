vl-string-search

(vl-string-search pattern string [start-pos])

Locates a substring within a target string and returns its index position.

The function outputs the zero-based index of the first occurrence of the pattern. Returns 0 if no match is detected. When the optional start-pos argument is provided, scanning begins from the specified index position in the target string.

Examples

Code Result
(vl-string-search "abc" "xyz-abc") 4
(vl-string-search "abc" "abc-xyz-abc" 2) 8

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (vl-string-search "中" "你好中望")

  • When LISPSYS is 1, the result is "2".
  • When LISPSYS is 0, the result may not be as expected.
