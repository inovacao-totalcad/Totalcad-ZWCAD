vlax-curve-getEndParam

(vlax-curve-getEndParam curve-obj)

Returns the parameter of the endpoint of the curve.

If endpoint makes sense to the curve-obj, this function returns a real number representing an end parameter, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result
(command "line" "0,0" "20,30" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(vlax-curve-getEndParam vla_object) 		36.0555 (the length of the line)
