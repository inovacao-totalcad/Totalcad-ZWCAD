vl-member-if

(vl-member-if predicate-function list)

Tests each element in list by the predicate function.

This function tests each element in list by the predicate-function.

If predicate-function returns a T value, this function returns a list. A list contains the element that first passes the test and all elements following this in the original argument. If this function returns a nil, none of the elements passes the test condition.

The test function value can take one of the following forms:

predicate-function value
A symbol (function name)
'(LAMBDA (X Y) ...)
(FUNCTION (LAMBDA (X Y) ...))

Examples

Code Result
(vl-member-if '(lambda (x)(= (abs x) 100)) '(4 7 100 -100 -3 -4)) (100 -100 -3 -4)
(vl-member-if '(lambda (x)(= (abs x) 30)) '(4 7 100 -100 -3 -4)) nil
