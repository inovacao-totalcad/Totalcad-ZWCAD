vlr-reactors

(vlr-reactors [reactor-type...])

If the reactor-type is existing, it returns the list of the reactor types you specified. And if you omit the reactor-type, it returns all the reactors existed in current graph space.

parameters

reactor-type

the reactor type.

Examples

Code Result
(vlr-reactors) Displays a list of all the list reactor types in current graph.
(vlr-reactors :vlr-object-reactor) Returns ((:VLR-Object-Reactor #<VLR-Object-Reactor> #<VLR-Object-Reactor>)) if a object reactor has been attached to current graph space;returns nil if not.
