vlax-create-object

(vlax-create-object prog-id)

Creates a new instance of a specified application object.

Use this function when you want to start a new instance of an application, and an object of the type specified by <Component> (see the argument description) to be created. If an application object has registered itself as a single-instance object, only one instance of the object is created, no matter how many times you call this function. If prog-id is a registered ActiveX object, this function returns the application object (VLA-object), otherwise nil.

The function accepts one argument:

Argument Meaning
prog-id A string containing the programmatic identifier of the desired ActiveX object, its format is as following:
<Vendor>.<Component>.<Version>
eg: excel.application.12

Examples

Code Result
(vlax-create-object "ZwCAD.Drawing") #<VLA-OBJECT IZcadDocument 231ee255198>
