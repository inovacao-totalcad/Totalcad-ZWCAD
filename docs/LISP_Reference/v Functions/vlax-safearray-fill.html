vlax-safearray-fill

(vlax-safearray-fill var 'element-values)

Assigns data to the elements of a safearray.

If the length of the list specified by "element-values" argument is fewer or more than the number of the var's elements, this function prompts "too few arguments" or "too many arguments", otherwise returns the safearray specified by "var" argument.

The function accepts two arguments:

Argument Meaning
var A safearray.
element-values A list of values to be stored in the array.

Examples

Code Result
(setq var (vlax-make-safearray vlax-vbsingle '(0 . 2)))
(vlax-safearray-fill var (list 1.2 2.3 3.4)) 		#<safearray...>

Note

For a multidimensional array variable, elements should be provided as nested lists, with each sublist aligning with the array's dimensional structure.
