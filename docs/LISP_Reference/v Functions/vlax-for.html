vlax-for

(vlax-for symbol collection [expression1 [expression2 ...]])

Iterates through a collection of VLA-objects, evaluating each expression.

This function returns the value of the last expression evaluated for the last object in the collection.

The function accepts two arguments at least and some optional arguments:

Argument Meaning
symbol A symbol to be assigned to each VLA-object in a collection.
collection A collection of VLA-objects.
expression1, expression2... The expressions to be evaluated.

Examples

Code Result
(vl-load-com)
(setq mycad (vlax-get-acad-object))
(setq mydoc (vlax-get-property mycad 'ActiveDocument))
