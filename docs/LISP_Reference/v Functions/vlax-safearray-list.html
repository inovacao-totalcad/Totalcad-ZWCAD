vlax-safearray->list

(vlax-safearray->list var)

Returns the elements of a safearray in list form.

If var doesn't represent a safearray, this function returns an error message, otherwise a list contains all elements of the array.

The function accepts one argument:

Argument Meaning
var A safearray.

Examples

Code Result
(setq var (vlax-make-safearray vlax-vbsingle '(0 . 2) '(0 . 2)))
(vlax-safearray-fill matrix '(("00" "01" "02") ("10" "11" "12") ("20" "21" "22")))
(vlax-safearray->list matrix) 		(("00" "01" "02") ("10" "11" "12") ("20" "21" "22"))
