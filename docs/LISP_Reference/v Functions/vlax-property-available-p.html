vlax-property-available-p

(vlax-property-available-p obj prop [check-modify])

Determines whether a VLA object has a specified property.

When nil or nothing is specified for check-modify argument, if the VLA object has the specified property, this function returns T, otherwise nil; When T or other not nil value is specified for check-modify argument, this function returns nil if either the VLA object hasn't the specified property or the value of the porperty can't be modified.

The function accepts two essential arguments and one optional argument:

Argument Meaning
obj A VLA object.
prop A string or symbol representing the name of the property to be tested.
check-modify Determines checking that the value of the property can be modified or not.

Examples

Code Result
(vlax-property-available-p line-obj 'Color) T

Determines if line object has color property.

(vlax-property-available-p line-obj 'Handle T) nil

Determines if line object has handle property and the value of handle property can be modified.

(vlax-property-available-p line-obj 'Area) nil

Determines if line object has area property.
