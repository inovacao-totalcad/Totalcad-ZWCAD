vl-string->list

(vl-string->list string)

Transforms each character in a string to its ASCII code representation.

The returned list contains integer values corresponding to the ASCII codes of all characters in the input string.

Examples

Code Result
(vl-string->list "abcd") (97.0000 98.0000 99.0000 100.0000)
(vl-string->list "?%") (63.0000 37.0000)

(vl-list->string char-codes-list)

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (vl-string->list "中望")

  • When LISPSYS is 1, the result is "(20013 26395)".
  • When LISPSYS is 0, the result may not be as expected.
