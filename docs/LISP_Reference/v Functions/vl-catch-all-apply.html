vl-catch-all-apply

(vl-catch-all-apply 'function list)

Passes a list of arguments to a specified function and intercepts any exceptions.

If the function invoked by vl-catch-all-apply completes successfully, it is the same as using apply. The benefit of using vl-catch-all-apply is that it allows you to intercept errors and continue processing. When you use apply, an exception occurs and an error message displays.

The function accepts two arguments:

Argument Meaning
'function A symbol identifying a defun, or a lambda expression
list A list containing arguments to be passed to the function

Examples

Code Result
(setq catchit (vl-catch-all-apply '/ (list 100 10))) 10
(setq catchit (vl-catch-all-apply '/ (list 100 0))) #<%catch-all-apply-error%>

Note

The vl-catch-all-apply function captures exceptions and returns an error object. The vl-catch-all-error-message function should be used to retrieve the corresponding error details.
