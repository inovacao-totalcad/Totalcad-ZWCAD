vl-file-copy

(vl-file-copy source-file destination-file [append])

Transfers data from a source file to a destination file, with optional content appending.

This function replicates the content of the source-file (a string path) into the destination-file (a string path). The optional append parameter, if active, merges source content to the destination instead of replacing it.

Returns a non-zero integer on success. Returns nil if the operation fails due to invalid paths, permissions, or I/O errors.

Examples

Code Result
(vl-file-copy "d:/test1.txt" "d:/test3.txt") 3
(vl-file-copy "d:/test1.txt" "d:/test2.txt") nil
(vl-file-copy "d:/test1.txt" "d:/test2.txt"T ) 3

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (VL-FILE-COPY "D:/tmp/?????.txt" "D:/tmp/?????111.txt")

  • When LISPSYS is 1, the result is "1".
  • When LISPSYS is 0, the result may not be as expected.
