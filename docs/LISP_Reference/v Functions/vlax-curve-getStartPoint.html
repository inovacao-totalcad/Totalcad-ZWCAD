vlax-curve-getStartPoint

(vlax-curve-getStartPoint curve-obj)

Returns the startpoint of the curve.

If startpoint makes sense to the curve-obj, this function returns a 3D point list representing a startpoint, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result
(command "ellipse" "C" "0,0" "15,0" 6)
(command "move" "l" "" "0,0" "@10.5,16.8")
(setq vla_object (vlax-ename->vla-object (entlast)))
(command "ucs" "O" "100,100")
(vlax-curve-getStartPoint vla_object) 		(25.5000 16.8000 0.000000) (in WCS)

Note

This function provides the coordinates of the startpoint in the World Coordinate System (WCS), regardless of whether the active coordinate system is UCS.
