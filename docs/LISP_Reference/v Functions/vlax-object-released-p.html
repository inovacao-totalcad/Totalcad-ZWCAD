vlax-object-released-p

(vlax-object-released-p obj)

Determines whether the specified argument with VLA object data type has been released.

Attentions

Erasing a VLA-object (using command ERASE or vla-erase) does not release the object. A VLA-object is not released until you invoke vlax-release-object on the object, or normal AutoLISP garbage collection occurs, or the drawing database is destroyed at the end of the drawing session.

If obj argument represents a VLA object and it has been released, this function returns T, otherwise nil. If this argument doesn't represent VLA object, ZWCAD will reports "error: bad argument type".

The function accepts one argument:

Argument Meaning
obj A VLA object.

Examples

Code Result 
(setq obj (vlax-ename->vla-object
	    (car (entsel "\nselect a line: "))
	  )
)
(vlax-object-released-p obj)
nil

The obj argument represents a line object, and the argument isn't released. 

(setq obj (vlax-ename->vla-object
	    (car (entsel "\nselect a line: "))
	  )
)
(vlax-release-object obj)
(vlax-object-released-p obj)
T

The obj argument represents a line object, and the argument has been released by vlax-release-object function.
