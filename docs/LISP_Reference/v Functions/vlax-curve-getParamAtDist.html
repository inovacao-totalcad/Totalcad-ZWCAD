vlax-curve-getParamAtDist

(vlax-curve-getParamAtDist curve-obj dist)

Returns the parameter of a curve at the specified distance from the beginning of the curve.

This function returns a real number representing an parameter, if successful; otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
dist A number specifying the distance from the beginning of the curve.

Examples

Code Result
(command "spline" "0,0" "6,7" "12,2" "22,8" "" "" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(vlax-curve-getParamAtDist vla_object 10.0) 		9.59229
