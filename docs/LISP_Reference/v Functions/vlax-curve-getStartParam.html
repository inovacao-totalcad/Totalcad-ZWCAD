vlax-curve-getStartParam

(vlax-curve-getStartParam curve-obj)

Returns the parameter of the startpoint of the curve.

If startpoint makes sense to the curve-obj, this function returns a real number representing a start parameter, otherwise nil.

The function accepts one argument:

Argument Meaning
curve-obj A VLA-object.

Examples

Code Result
(command "spline" "0,0" "6,7" "12,2" "22,8" "" "" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(vlax-curve-getStartParam vla_object) 		0.000000
