vl-file-size

(vl-file-size filename)

Returns the byte count of a specified file.

When the file cannot be accessed, this function yields nil. A 0 result indicates either a directory path or zero-byte file. A positive integer confirms successful file measurement.

Typical applications include verifying file existence before operations or monitoring storage allocation.

Examples

Code Result
(vl-file-size "d:/test.txt") 234
(vl-file-size "e:") 0
