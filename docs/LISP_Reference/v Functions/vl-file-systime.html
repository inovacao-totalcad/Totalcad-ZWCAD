vl-file-systime

(vl-file-systime filename)

Retrieves timestamp details for the most recent update of a given file.

The function outputs a six-element list in this order: year (YYYY), month (MM), weekday number, day of month (DD), hours (HH), minutes (MM), and seconds (SS).

Returns nil if the file cannot be accessed or doesn't exist.

Usage Example

Sample output for an existing file sample.dwg:

Expression Output
(vl-file-systime "c:/designs/sample.dwg") (2023 11 2 15 9 30)

Interpretation

The timestamp indicates the file was last updated on November 15th, 2023 (Wednesday) at 09:09:30 AM.

Examples

Code Result
(vl-file-systime "d:/test.txt") (2012 8 3 5 16 17 24)

Note

The file's last modification occurred on August 5, 2012, a Wednesday (the third weekday), at 16:17:24.
