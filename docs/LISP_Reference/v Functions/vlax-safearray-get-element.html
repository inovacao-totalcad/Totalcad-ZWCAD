vlax-safearray-get-element

(vlax-safearray-get-element var element...)

Returns an element from an array.

If the specified indexes of the element make sense to the safearray, this function returns the specified element's value, otherwise prompts an error message.

The function accepts two arguments at least:

Argument Meaning
var A safearray.
element A integer representing the indexes of the element in the array, the number of element argument depends on the number of the dimension in the array.

Examples

Code Result
(setq matrix (vlax-make-safearray vlax-vbString '(0 . 2) '(0 . 2)))
(vlax-safearray-fill matrix '(("00" "01" "02") ("10" "11" "12") ("20" "21" "22")))
(vlax-safearray-get-element matrix 1 2) 		"12"
