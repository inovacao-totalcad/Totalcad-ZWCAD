vlax-variant-value

(vlax-variant-value var)

Returns the value of a variant.

If the specified var argument doesn't represent a variant, this function prompts "error: bad argument type", otherwise returns the value of var.

The function accepts one argument:

Argument Meaning
var A variable.

Examples

Code Result
(setq varInt (vlax-make-variant 12 vlax-vbInteger))
(vlax-variant-value varInt) 		12
