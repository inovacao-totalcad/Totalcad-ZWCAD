vlax-dump-object

(vlax-dump-object vla-object [T])

List a VLA-object's properties or properties and methods.

If T parameter isn't specified, this function will list all properties of the vla-object, return the name of this object, and list all methods of the vla-object additionally and returns T.

The function accepts one argument and one optional argument:

Argument Meaning
vla-object A VlA-object.
T If specified, this function also lists all methods of the VLA-object.
