vl-cmdf

(vl-cmdf [arguments] ...)

Executes a ZWCAD command.

This function evaluates all the supplied arguments before executing the ZWCAD command, and will not execute the ZWCAD command if it detects an error during argument evaluation.

The function accepts some optional arguments:

Argument Meaning Note
arguments ZWCAD commands and their options They can be strings, reals, integers or points, as expected by the prompt sequence of the executed command. A null string ("") is equivalent to pressing ENTER on the keyboard. Invoking the function without any arguments is equivalent to pressing ESC and cancels most ZWCAD commands.

Examples

Code Result Note
(vl-cmdf "line" '(0 0) '(100 200) (200 300) "") error: bad function Because vl-cmdf evaluates each argument before passing the command to ZWCAD, the invalid point list (200 300) is detected and the command is not executed.
