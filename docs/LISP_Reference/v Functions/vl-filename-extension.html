vl-filename-extension

(vl-filename-extension filename)

Retrieves the extension component from a specified file path string.

This function isolates and returns the file type suffix (including the dot separator) while excluding both the primary filename and directory structure information.

Examples

Code Result
(vl-filename-extension "C:/Program files/ZWCAD 2025 Eng/zwcad.exe") ".EXE"
(vl-filename-extension "zwcad.exe") ".EXE"
