vl-registry-descendents

(vl-registry-descendents reg-key [val-names])

Displays a list.

This function displays a list. A list contains the specified value names or all subkeys of reg-key. If this function returns the specified value names, the val-names is existed and is not a nil. If this function returns all subkeys of reg-key, the val-names is not exist.

Examples

Code Result
(vl-registry-descendents "HKEY_CURRENT_USER\\Software\\Chinaweal Longteng\\ZWCAD 2025 Chs\\Profiles") ("zwjx")
(vl-registry-descendents "HKEY_CURRENT_USER\\Software\\Chinaweal Longteng\\ZWCAD 2025 Chs\\Profiles" "PreviousProfile") ("")
