vlax-safearray-type

(vlax-safearray-type var)

Returns the data type of a safearray.

If the specified var argument represents a safearray, this funtion returns an integer whose meaning can be inquired in the following table:

Integer constant String constant
2 Integer (vlax-vbInteger)
3 Long integer (vlax-vbLong)
4 Single-precision floating-point number (vlax-vbSingle)
5 Double-precision floating-point number (vlax-vbDouble)
8 String (vlax-vbString)
11 Boolean (vlax-vbBoolean)
12 Variant (vlax-vbVariant)

The function accepts two arguments at least and some optional argument:

Argument Meaning
var A safearray.

Examples

Code Result
(setq 3dpoint (vlax-make-safearray vlax-vbSingle '(0 . 2)))
(vlax-safearray-type 3dpoint) 		4
