vlax-curve-getPointAtParam

(vlax-curve-getPointAtParam curve-obj param)

Returns the point at the specified parameter value along the curve.

If the specified parameter is less than or equal to the EndParam(return by the vlax-curve-getEndParam function) of the curve, this function returns a 3D point list representing a point on the curve, otherwise nil.

The function accepts two arguments:

Argument Meaning
curve-obj A VLA-object.
param A number specifying a parameter on the curve.

Examples

Code Result
(command "spline" "0,0" "6,7" "12,2" "22,8" "" "" "")
(setq vla_object (vlax-ename->vla-object (entlast)))
(setq length (vlax-curve-getEndParam vla_object))
(command "ucs" "O" "100,100")
(vlax-curve-getPointAtParam vla_object (/ length 2.0)) 		(9.84327 3.74107 0.000000) (the middle point of the spline)

Note

This function provides the XYZ coordinates of a point in the World Coordinate System (WCS) regardless of the currently active UCS configuration.
