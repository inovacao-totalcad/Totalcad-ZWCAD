dictrename
(dictrename ename oldkey newkey)
Modifies the key name of an existing entry within a specified dictionary.
This function changes the identifier oldkey to newkey in the dictionary referenced by ename. The operation will fail and return nil if: the target dictionary is invalid, the original key does not exist, the new key is already present, or invalid parameters are supplied. Successful execution returns the updated key name.
