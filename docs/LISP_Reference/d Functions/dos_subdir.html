dos_subdir

(dos_subdir [path [T]])

Return list of subdir in given dir without (\\).

Parameters

path
Given path. Use current path if not given.

T
Return current dir "." and parent dir "..". Not return in default.

Returns

List of subdir if successful.
nil on error.

Example

Code Result
(dos_subdir) ("en-US" "Express" "Fonts" "Help" "PlotStyles" "Plotters" "Sample" "Support" "Template" "UserDataCache" "WebServices")
