done_dialog

(done_dialog [flag])

Closes the active dialog box.

This function exits the current dialog and provides the x,y coordinates of its position, allowing subsequent start_dialog calls to reposition it accordingly.

The optional flag parameter sets a return code for the start_dialog function. When the flag exceeds 1, start_dialog returns this value directly. For values 1 or below, standard status codes apply:

Value Description
0 Dialog was canceled by user
1 Dialog was accepted by user

Examples

Code
(setq dlg (start_dialog))
(done_dialog dlg)
