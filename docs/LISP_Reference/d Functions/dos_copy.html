dos_copy

(dos_copy source destination)

Copy one or more files from dir or drive to another.

Parameters

source
Source files. Source can contain wildcard characters("*" and "?").

destination
Destination dir or file.

Returns

T if successful.
nil on error.

Example

Code Result
(dos_copy "C:\\Drawings\\test1.dwg" "C:\\Drawings\\test2.dwg") T
(dos_copy "C:\\Drawings\\test1.dwg" "C:\\Temp\\") T
(dos_copy "C:\\Drawings\\*.dwg" "C:\\Temp\\") T
