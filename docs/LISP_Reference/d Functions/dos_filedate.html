dos_filedate

(dos_filedate filespec)

Returns a list containing filenames and ZWCAD calendar dates. Use rtos and substr or dos_strleft to extract elements from the ZWCAD calendar date.

Parameters

filespec
The desired file or files. filespec can contain wildcard characters ("*" and "?"). If filespec is not supplied, it is assumed to be *.*.

Returns

An association list containing filenames and their corresponding dates in ZWCAD calendar date format if successful.
nil on error.

Example

Code Result
(dos_filedate "C:\\Program Files\\ZWCAD 2012\\Support\\*.lsp") (("ZWCAD2012.lsp" . 20130331) ("ZWCAD2012doc.lsp" . 20130327) ("ZWmvsetup.lsp" . 20130323))
