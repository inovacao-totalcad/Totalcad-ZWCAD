dos_orderlist

(dos_orderlist title prompt list [strings])

Displays a layer list in a sizeable window dialog box , and you can reorder the items in the list by dragging or by clicking up/down/top/bottom button.

Parameters

title
A string of the title for the dialog box.

prompt
A string of the dialog prompt.

list

A list of string that contains the strings to be displayed in the list of the dialog box.

strings

If not specified or T, a list of ordered strings is returned, if nil, alist of intergers that identify the ordered strings is returned.

Returns

A list of the selected strings if successful.
nil on error or cancel.

Example

Code Result
(dos_subdir) (setq list1 (list "Layer1" "Layer2" "Layer3" "Layer4" "Layer5" "Layer6"))
(dos_orderlist "Layers" "Drag to reorder layers" list1)
