dictsearch

(dictsearch ename symbol [setnext])

Retrieves a dictionary entry by key.

This function locates an entry within a specified dictionary entity (ename) using a lookup string (symbol). When the optional setnext parameter is non-nil, it modifies the internal traversal counter for subsequent dictnext operations to resume after the found entry.
