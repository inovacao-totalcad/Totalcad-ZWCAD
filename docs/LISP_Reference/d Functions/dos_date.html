dos_date

(dos_date [date])

Returns the current system date or changes the current system date to one specified.

Parameters

date
A list of numbers specifying the year (1970 to 10000), month (1 to 12), and day (1 to 31).

Returns

A list of numbers identifying the current year, month, and day if successful.
nil on error.

Example

Code Result
(dos_date) (2012 10 1)
(dos_date '(2012 12 1)) (2012 12 1)
