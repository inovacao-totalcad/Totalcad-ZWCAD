dos_dirtree

(dos_dirtree [path])

Returns a list of directories and any subdirectories found in the specified directory.

Parameters

path
A string containing an existing path. If not specified, the current directory is used.

Returns

A list of subdirectories if successful.
nil on error.

Example

Code Result
(dos_dirtree "C:\\Program Files\\ZWCAD 2012\\Support\\") ("C:\\Program Files\\ZWCAD 2012\\Support\\" "C:\\Program Files\\ZWCAD
2012\\Support\\color")
