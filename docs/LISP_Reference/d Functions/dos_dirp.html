dos_dirp

(dos_dirp path)

Check for the existence of a directory.

Parameters

path
A string containing an existing path.

Returns

T if the directory exists.
nil if the directory does not exist, or on error.

Example

Code Result
(dos_dirp "C:\\Program Files\\ZWCAD 2012\\") T
(dos_dirp "C:\\Program Files\\ZWCAD 2013\\") nil
