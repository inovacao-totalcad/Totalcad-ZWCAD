defun-q

(defun-q [c:] name ([arg1 arg2 ...] / [local-var1 local-var2 ...]) expression)

Defines an editable LISP routine stored as list data.

Enables function modification through list operations by retaining its definition structure for programmatic access.

Important

While defun-q shares functional parity with defun, it maintains the routine's components as accessible list elements via (defun-q-list-ref 'name). Primarily retained for backward compatibility with existing LISP implementations.
