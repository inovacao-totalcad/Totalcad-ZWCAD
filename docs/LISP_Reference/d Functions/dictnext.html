dictnext

(dictnext ename [rewill])

Retrieves subsequent entries from a dictionary object.

This function sequentially accesses elements within a specified dictionary (ename). When the rewill parameter is supplied with a non-nil value, it resets the iteration pointer and returns the initial entry of the dictionary.
