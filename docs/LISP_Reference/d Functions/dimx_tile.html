dimx_tile

(dimx_tile key)

Retrieves the width measurement of a specified dialog tile.

When combined with dimy_tile, this function provides dimensional data for the interface element identified by key. The returned values are commonly utilized in layout calculations and graphical functions like vector_image for precise element positioning.

Examples

Code
(dimx_tile "image")

Note

  • The dimension returned is one less than the size, since the dimension begins at 0. Thus, for the example above, the size of the tile is 16 x 16.

  • The key is a case-sensitive string.
