(=)(Equal to operator)

(= item1 item2 ...)

Returns T if all items are identical.

This operator evaluates value equivalence between multiple elements:

  • Returns T when comparative elements match exactly
  • Any discrepancy results in nil output

For multiple arguments, sequential comparison is performed where each element must equal its predecessor to maintain truth. Supports numeric values and string data types.

Examples

Code Result
(= 20 20) T
(= 5.0 5 5.0) T
(= "ZWCAD" "zwcad") nil
(= 4 3.9) nil
(= "Hello" ) T

Note

Differentiate between the = and equal functions: = evaluates numeric values and text strings, whereas equal handles comparisons of list data structures.

Both = and equal are comparison operators, not arithmetic evaluators for expressions like 1 + 2 = 3. In LISP, arithmetic operations are handled through functions like +, with comparisons performed separately, while setq assigns values to variables.
