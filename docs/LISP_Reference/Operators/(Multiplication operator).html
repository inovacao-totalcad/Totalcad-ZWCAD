(*)(Multiplication operator)

(* number1 number2 ...)

Calculate the product of specified numeric values.

This function processes both integers and real numbers. If all arguments are integers, the result will be an integer. The presence of any real number converts the final output to a real data type.

When operating exclusively on real numbers, the return value remains real. Mixed-type calculations automatically promote the result to real for precision.

Examples

Code Result
(* 2 9) 18
(* 1.3 2.4) 3.12000
(* 60 -10 50) -30000
(* 3) 3
(*) 0
