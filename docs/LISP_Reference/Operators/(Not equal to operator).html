(/=)(Not equal to operator)

(/= item1 item2 ...)

Evaluates inequality between elements.

This function checks for non-equality across arguments:

  • Returns T when the first argument differs from the second.
  • All subsequent comparisons must remain unequal for T to be returned.
  • Returns nil if any two consecutive elements match.

For multiple arguments, T requires complete uniqueness across all elements. Compatible with numerical values and text strings.

Examples

Code Result
(/= 2.4 2.4 2.4) nil
(/= "ME" "me") T
(/= "*" "*") nil
(/= -6 -6) nil
(/= 7) T

Note

Comparison operators like = (equality operator) and < (less-than operator) are frequently combined with control structures such as if, while, and cond expressions. These operators help evaluate logical conditions (e.g., checking whether a variable reaches zero) to control program flow, such as terminating a loop when a value exceeds a threshold (e.g., while maintaining i < 5).
