(+)(Addition operator)

(+number1 number2 ...)

Computes the sum of the provided numeric values.

Returns the arithmetic total of input parameters. Accepts both integer and floating-point values. When all operands are integers, the output will be an integer. Mixed input types (integers and floating-points) will produce a floating-point result regardless of decimal positions.

Examples

Code Result
(+ 10 20) 30
(+ 10 2 3) 15
(+ 2.3 2.4) 4.70000
(+ 5 ) 5
(+ ) 0
