1-(decrement)

(1-number)

Decrements the input value by one.

Returns a number reduced by 1 from the original numeric argument, which can be either integer or real. Requires precisely one numeric parameter for execution.

Examples

Code Result
(1- 0) -1
(1- 7.6) 6.60000
(1- -12) -13

Note

This function serves as a decreasing numerical iterator in operational workflows.
