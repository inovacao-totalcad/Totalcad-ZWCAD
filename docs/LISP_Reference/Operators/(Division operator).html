(/)(Division operator)

(/ number1 number2 ...)

Computes sequential division starting with the first argument divided by subsequent arguments.

This function returns the arithmetic quotient. When given two operands, it returns number1/number2. When multiple operands are present, the result equals number1 divided by the multiplicative combination of all subsequent arguments.

Accepts both integer and floating-point values. Division operations containing exclusively integers yield an integer result. Mixed numeric types automatically promote integer values to floating-point format, with the operation returning a floating-point value regardless of operand count.

Examples

Code Result
(/ 4 2) 2
(/ 5.8 2) 2.90000
(/ 60 -10 3) -2
(/ 3) 3
(/) 0

Note

Ensure a leading digit precedes any decimal point.
