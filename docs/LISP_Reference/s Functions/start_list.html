start_list

(start_list key [operation [index]])

Initializes configuration of a list control element.

This routine prepares a dialog list component identified by key for modification. The operation parameter specifies the type of list manipulation (defaults to 3) with these options:

Op Code Description
1 Modify existing list entries
2 Add entries to the list's end
3 Overwrite entire list contents (default)

The index parameter applies exclusively to modification operations (Op 1), indicating the position of the item to alter. List positions are zero-indexed (0 = first entry, 1 = second, etc.).

Examples

Code Result
(start_list key) or (start_list key 3)
(start_list key 1 2)
(start_list key 2) 		start a new list.
Same action as above.
Change the 2nd item.
Add data.

Note

This function is utilized for constructing list boxes and drop-down menus in DCL interfaces. For implementation demonstrations with DCL components, consult the examples provided under list_box and popup_list entries.
