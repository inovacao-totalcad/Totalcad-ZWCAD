strcase

(strcase string [flag])

Alters character case representation in a given string.

This operation modifies alphabetical characters to either uppercase (default) or lowercase format depending on the optional flag parameter. When the flag argument is absent or explicitly set to nil, the conversion produces uppercase output. Specifying a non-nil value (commonly T) inverts the behavior, generating lowercase characters instead.

Non-alphabetic characters within the input string remain unchanged regardless of the flag setting. The transformation affects only letters from A-Z in the ASCII character set.

Examples

Code Result
(strcase "zwcad") "ZWCAD"
(strcase "HELLO"T) "hello"
