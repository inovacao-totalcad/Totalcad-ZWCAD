ssget

(ssget [mode] [point1 [point2]] [point-list] [filter-list])

Prompts the user to create a selection set.

When called without arguments, this function displays a "Select objects:" prompt and allows interactive selection. This is the only scenario where selected entities are graphically highlighted. The function returns a selection set identifier like <Selection set: c8260a10>. Note that attributes and polyline vertices are excluded from selection sets.

The mode parameter determines the selection technique:

Mode Selection Method Arguments Sample Call
Simple selection point1 (ssget) or (ssget '(5 7))
"C" Crossing window point1 point2 (ssget "C" '(0 0) '(10 5))
"CP" Polygonal crossing points-list (ssget "CP" polyPts)
"F" Fence selection points-list (ssget "F" fencePoints)
"I" Implied selection none (ssget "I")
"L" Last created entity none (ssget "L")
"P" Previous selection set none (ssget "P")
"W" Window selection point1 point2 (ssget "W" '(1 2) '(8 6))
"WP" Polygonal window points-list (ssget "WP" windowPts)
"X" Database scan none (ssget "X")
":S" Single-selection mode none (ssget ":S")

The "I" mode accesses preselected entities when PICKFIRST is enabled.

Coordinate arguments (point1, point2) define selection areas based on the chosen mode.

The filter-list uses dotted pairs to specify entity properties:

(ssget "X" '((0 . "LINE") (62 . 5)))

selects all blue lines. Relational tests use the -4 group code:

(ssget "X" '((0 . "ARC") (-4 . ">=") (40 . 10.0))

selects all arcs with radius >= 10 units. Supported operators:

Operator Function
"&" Bitwise AND (integers)
"&=" Bitwise equality (integers)
"*" Wildcard match (strings)
"=" Equality test
"!=" Inequality test
"/=" Inequality test
"<>" Inequality test
"<" Less than
"<=" Less than or equal
">" Greater than
">=" Greater than or equal

Bitwise operators work exclusively with integers. The asterisk (*) is string-specific.

Important

Entity snap settings do not affect ssget selections.
