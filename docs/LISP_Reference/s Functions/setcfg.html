setcfg

(setcfg parameter value)

Configures specified parameter with given value in ZWCAD's registry settings.

This function modifies entries within the Windows registry path:
HKEY_CURRENT_USER\Software\ZWSOFT\ZWCAD\2026\en-US\Settings\UserConfig\SetCfg (English version path shown). Accepts string or numeric values. The parameter argument must follow this hierarchical format:

"AppData/application/section/key"

Structure breakdown:

Component Description
AppData Root configuration category
application ZWCAD module or plugin identifier
section Configuration group within application
key Specific setting to modify

Note: Modifications affect user-specific profiles and persist between sessions. Verify registry permissions before deployment.

Examples

Code Result
(setcfg "AppData/application/section/key" "user_data") 56
