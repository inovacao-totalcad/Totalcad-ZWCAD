ssname

(ssname selection-set index)

Retrieve the entity at a specific position within a selection set.

This function outputs the entity name associated with the specified index position in the selection-set. The index follows zero-based numbering where position 0 represents the first captured entity, position 1 indicates the second captured entity, and subsequent positions follow this pattern based on creation order within the set.
