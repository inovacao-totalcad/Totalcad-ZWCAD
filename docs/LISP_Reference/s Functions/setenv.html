setenv

(setenv variable value)

Assigns a specified value to a system environment variable within the ZWCAD application context.

This function modifies or creates global environment parameters accessible during the current ZWCAD session. For persistent system variables, use platform-specific configuration methods.

Implementation Notes

  • New variables created through this function are maintained in ZWCAD's runtime memory and may not be visible in external system terminals.
  • When modifying ZWCAD-specific configuration variables (e.g., ZWCAD_PREFIX), values are automatically routed to appropriate internal registry entries.
  • Environment changes take immediate effect for subsequent commands but do not alter system-level configurations.

Examples

Code Result
(setenv "tmp" "one") "one"
