ssdel

(ssdel ename ss)

Removes a specified entity from the selection set.

Both parameters are required: ename (entity to remove) and ss (target selection set). Unlike similar functions, omitting either argument will result in an error.

Returns the modified selection set if the entity is successfully removed. If the specified entity does not exist in the original set, returns nil without modifying the selection set.

Examples

Code Result
(ssdel en ss) Delete entity en from selection set ss.
