subst

(subst new old list)

Performs element replacement within list structures.

This list operation replaces all instances of the 'old' element with the 'new' element throughout the specified list. While conceptually similar to pattern replacement in text processing, subst exclusively operates on nested list elements rather than string values.

Frequently employed in conjunction with the assoc function, subst enables dynamic modification of association list entries, particularly when working with CAD-specific data structures containing dotted pairs.

Examples

Code Result
(subst '2 '3 '(3 10)) (2 10)
(subst 'w 'o '(o our)) (W OUR)
