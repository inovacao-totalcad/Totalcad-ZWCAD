ssadd

(ssadd [en [ss]])

Constructs or modifies entity groups.

This operation either generates a fresh selection set (when called without parameters) or expands an existing collection. The function supports three invocation patterns:

Syntax Behavior
(ssadd) Initializes an empty selection container
(ssadd en) Generates a selection container holding the specified entity
(ssadd en ss) Appends the entity to a preexisting selection container

Returns the selection container identifier in the format:

<Selection container: 2614B0C0>

ZWCAD permits concurrent operation with multiple selection containers.

Examples

Code Comments
(setq ss (ssadd))
(ssadd en ss) 		Create a new selection set ss.
Adds entity en to ss.
