setq

(setq symbol1 value1 [symbol2 value2] ...)

Assigns specified values to corresponding symbols.

As the primary function for variable assignment in LISP, this sets value1 to symbol1. Multiple pairs can be assigned sequentially. For instance:

(setq radius 5.2 material "steel")

assigns both a numerical value and string to respective symbols.

Important

Distinguish from comparison operators like = which evaluate equality rather than modifying variables.

Each symbol receives its corresponding evaluated value expression, which may include numbers, quoted strings, or pre-defined variables. When multiple assignments occur, the final pair's value becomes the function's return value. Uninitialized symbols default to nil.

Examples

Code Result
(setq a 9) 9
(setq a 6 b 7) 7
(setq c) nil
