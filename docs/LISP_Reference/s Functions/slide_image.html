slide_image

(slide_image x y width height slide)

Renders a graphical slide within dialog controls.

This method positions a slide image at specified coordinates (x,y) representing the top-left origin point. The image extends horizontally by the defined width value along the positive x-axis and vertically by the height parameter along the downward y-axis.

Supported formats include SLD slide files, Windows Metafiles (WMF), and Enhanced Metafiles (EMF). ZWCAD locates slide resources through configured library paths.

Width and height parameters define the display dimensions of the image within the dialog layout.

Examples

Code Result
(slide_image 10 10 15 20 "image.sld") nil

Note

When generating an image with the MSlide command, maintain consistent dimensions and aspect ratio (typically 4:3) matching your dialog's display requirements for optimal clarity.
