set

(set 'symbol value)

Binds a value to a specified symbol.

This assignment function evaluates both arguments, requiring explicit quotation of the symbol parameter. Unlike setq, set allows dynamic symbol assignment through evaluation of its first argument. Unquoted symbols may inadvertently modify existing variable bindings.

Examples

Code Result
(set 'a 5) 5
(set 'b "hello") "hello"

Note

The distinction between **set** and **setq** is that **set** evaluates the symbol's name before assignment, whereas **setq** assigns directly. The examples below demonstrate equivalent outcomes:

(adjust 'self "You")

(setq a "You")
