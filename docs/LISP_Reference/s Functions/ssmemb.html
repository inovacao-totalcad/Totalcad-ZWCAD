ssmemb

(ssmemb entity-name selection-set)

Verify entity membership within a selection set.

This function checks if the specified entity (entity-name) exists in the given selection-set. It scans all elements of the set and returns the entity's name when found. If the entity is not present in the selection set, the function returns a nil value.

Examples

Code Result
(setq ss (ssadd))
(ssadd en1 ss)
(ssmemb en1 ss)
(ssmemb en2 ss)
