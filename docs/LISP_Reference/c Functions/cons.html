cons

(cons element sequence)

Prepends the specified element to a sequence, returning a new list.

This function generates a fresh list structure or constructs a dotted pair when combining two atomic values. Dotted pairs (formed by (cons element1 element2)) are particularly useful for managing entity attribute associations in ZWCAD applications.

The initial parameter defines the element to insert at the head position of the resultant sequence. Subsequent elements maintain their original order in the input sequence.

Nested list elements will be preserved as single entries within the new structure without automatic flattening.

Examples

Code Result
(cons '5 '6c) (5 . 6C)
(cons 'one'(two three)) (ONE TWO THREE)
