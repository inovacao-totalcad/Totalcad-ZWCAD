cdr

(cdr list)

Returns all elements of the list excluding the initial entry.

As a fundamental list decomposition function, cdr provides sequential access to list contents. When applied to a list, it returns a new sublist containing elements from the second position onward. For example, executing (cdr '("red" 15 [20,40] nil)) results in (15 [20,40] nil). This function is particularly useful for iterative list processing and data structure manipulation.

Examples

Code Result
(cdr '(9 5 8)) (5 8)
(cdr '("one" "two")) ("two")
(cdr '(9)) nil
