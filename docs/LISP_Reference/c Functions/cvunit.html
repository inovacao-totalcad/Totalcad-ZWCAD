cvunit

(cvunit value from to)

Converts numerical values between unit systems.

Translates a measurement quantity specified by value from source units (from) to target units (to). Compatibility between unit types is required for conversion.

Sample usage: (cvunit 15 "meter" "foot") calculates equivalent length in feet. Returns nil if units are dimensionally inconsistent (e.g., converting time to distance).

Examples

Code Result
(cvunit 1 "m" "cm") 100.000
(cvunit 8 "day" "hour") 192.000
(cvunit 1 "minute" "second") 60.0000

Note

Numerical arrays or coordinate data may also undergo conversion, as demonstrated in the earlier illustrations.
