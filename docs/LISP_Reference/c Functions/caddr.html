caddr

(caddr list)

Get the third item of the list.

This function takes a list apart and returns the third element of the list. For example, if you had a list of points such as (1 2 3), the caddr function would return the third element of the list, or 3.

Examples

Code Result
(caddr '(5 3 6)) 6
(caddr '(8 9 str)) STR
(caddr '(4 9)) nil
