command

(command cmd [arguments] ...)

Executes a ZWCAD command within a LISP program.

This function enables integration of native ZWCAD commands into custom automation routines. Arguments provided are passed to the command. User inputs required by the command should be predefined using setq variables. Coordinate values must be captured via getpoint prior to assignment.

Certain commands may require additional input beyond specified parameters. To terminate such commands, supply an empty string (" ") to simulate pressing Enter and complete the operation.

Examples

Code
(setq pt1 '(2.0 3.0 0.0) pt2 '(7.0 9.0 0.0))
(command "line" pt1 pt2 "")
