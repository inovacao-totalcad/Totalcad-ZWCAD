trans

(trans point from to [flag])

Converts a point's coordinates between different reference frames.

This routine transforms spatial coordinates represented in one coordinate framework to another specified system.

The point parameter must be a 3-element list. Its interpretation varies based on the flag parameter's value.

  • The from parameter specifies the source coordinate system:

ID Reference Frame
0 Global coordinate framework (WCS)
1 Active user coordinate system (UCS)
2 Viewport display coordinates (DCS)
Use 0/1 for current viewport
Use 3 for model space viewport
3 Layout space display coordinates

  • The to parameter indicates the target system using the same ID codes

  • The flag parameter defines coordinate interpretation:

Flag Behavior
T Vector translation mode
nil Standard position conversion

Examples

Code Result
(trans '(3.6 -4 5.4) 1 0) (3.60000 -6.64680 0.989949)
