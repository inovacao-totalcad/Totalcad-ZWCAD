type

(type obj)

Identifies the data classification of a given object.

Returns the data type classification (such as floating-point value, whole number, collection, graphic reference, etc.) for the specified object. The table below defines recognized type identifiers:

Type Code Description
ENAME Graphical entity reference
EXSUBR External SDS routine module
FILE Open resource handler
INT Whole numeric value
LIST Sequence container or custom operation
PAGETB Memory management registry
PICKSET Object selection group
REAL Decimal numeric value
STR Character sequence
SUBR Built-in LISP operation
SYM Named variable identifier

Examples

Code Result
(type 10) INT
(type "zwcad") STR
