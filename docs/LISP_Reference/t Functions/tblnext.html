tblnext

(tblnext table-name [flag])

Retrieves sequential entries from a specified symbol table.

This function accesses symbol table records in ZWCAD, returning either the initial entry or subsequent entries depending on the flag parameter. Supported table types include:

Symbol Table Description
"vport" Configuration settings for viewport layouts
"layer" Defined layer properties
"ltype" Line pattern definitions
"ucs" User coordinate system configurations
"dimstyle" Dimensioning specifications
"block" Grouped entity collections
"style" Font and text formatting presets
"view" Saved perspective configurations
"appid" Third-party application identifiers

The initial call returns the table's first entry as dotted pair values. Subsequent calls without flag modification progress through the table sequentially. Returns nil upon reaching the table's end.

Providing a non-nil flag (typically T) resets the iterator to the table's starting position.

Examples

Code Result
(tblnext "layer") ((0 . "LAYER") (2 . "0") (70 . 64) (6 . "Continuous") (62 . 7) (290 . 1) (370 . -3))
(tblnext "layer" T) ((0 . "LAYER") (2 . "0") (70 . 64) (6 . "Continuous") (62 . 7) (290 . 1) (370 . -3))
