member

(member item list)

Locate the initial instance of an element within a list.

This function returns a sublist starting from the first matched element through the list's end. It provides positional context for list modification operations when the exact element location is unknown. The result contains all subsequent elements following the identified item.

Examples

Code Result
(member '"two"'("one" "two")) ("two")
(member 'q '(x y z)) nil
