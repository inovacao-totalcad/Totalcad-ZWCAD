menucmd

(menucmd str)

Executes specified commands within the menu interface.

This function processes menu operations for cursor and dropdown menus. The input string must follow these syntax patterns:

  • "menu_specifier=action_code"
  • "menu_specifier=*"

Menu identifiers consist of two components separated by a dot. For example: (menucmd "G3.5=zwlogo")
"G3" denotes the third dropdown menu (typically View), ".5" indicates the fifth command item. Supported identifiers include:

Identifier Menu Type
G0 Contextual (right-click) menu
G1-G16 Primary dropdown menus 1 through 16

Action codes control menu item states:

Code Action
? Query current state
* Reveal hidden menu
~ Deactivate item (visual dimming)
!. Toggle selection indicator
[space] Clear special states
text Update item label text

Examples

Code Result
(menucmd "P3=*") Display menu #3 (the View menu).
(menucmd "P3.1=~") Disable menu #3, item #1 (the View | Redraw menu item).
