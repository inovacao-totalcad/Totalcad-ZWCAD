rtos

(rtos value [format-type [decimal-digits]])

Transforms a numerical value into its string representation.

This routine processes a real number to generate a formatted text output. The primary parameter value specifies the numerical input for conversion.

Optional parameters format-type (integer 1-5) and decimal-digits control the output formatting:

Format Code Display Style
1 Scientific notation
2 Fixed decimal
3 Engineering units
4 Architectural measurements
5 Fractional values

The decimal-digits parameter specifies rounding precision (0-8 decimal places), affecting all formats except architectural and fractional representations.

Examples

Code Result
(rtos 23 1 4) "2.3000E+01"
(rtos 34.7 3 2) "2'-11\""

Note

When omitted, the mode and precision parameters inherit their values from the system variables LUNITS (defaulting to decimal units) and LUPREC (defaulting to 4 decimal places). To leverage the active configuration without manual specification, exclude these arguments entirely.
