read-char

(read-char [file-handle])

Acquires one character from an input source.

This operation obtains a single character from either keyboard input or a specified file. When provided with a file-handle (as returned by the open function), it reads from the designated file. If no file-handle is supplied, input is captured from the standard keyboard device.

The function returns the integer ASCII value of the character rather than its textual representation. Use the chr function to convert this numerical code into a readable character.

Examples

Code Result
(read-char ) input: a
97
(read-char ) input: M
77

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (open "read-line.txt" "r") (read-char f) (close f)

  • When LISPSYS is 1, the result is "20320".
  • When LISPSYS is 0, the result may not be as expected.
