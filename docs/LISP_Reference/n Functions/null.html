null

(null item)

Check if the specified item evaluates to a nil value.

This function returns T when the item is nil, indicating an unbound state. All non-nil values will result in a nil return. Useful for validating variable states in conditional logic.

Examples

Code Result
(null (< 6 5)) T
(null "yes") nil

Note

  • The null function is the opposite of the boundp function.

  • The not and the null functions are very similar. The difference is that not checks whether the item is nil. Null is meant for testing for empty lists.
