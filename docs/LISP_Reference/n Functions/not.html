not

(not item)

Check if the specified item evaluates to nil.

This function tests whether item contains a nil value. It returns T for nil inputs and nil for all other values.

Examples

Code Result
(not (< 5 6)) nil
(not nil) T

Note

The **not** and **null** functions share similarities but differ in purpose: **null** specifically evaluates whether an expression resolves to **nil**, making it ideal for detecting empty lists, while **not** returns the logical inverse of any input.
