nentselp

(nentselp [prompt] [point])

Retrieves entity selection data through programmatic specification.

Similar to nentsel but optimized for non-interactive workflows, this function accepts predefined coordinates through the point parameter instead of requiring cursor input. The optional prompt parameter allows specifying a context message when user interaction might occur. If a point is provided, user interaction is bypassed for automated processing.

Examples

Code Result
(nentselp "Select a polyline: " '(187.151 150.912)) (<Entity name: 49dc500 > (187.151 150.912 0.000000))
