new_dialog

(new_dialog dialog dcl-id [action point])

Initializes and displays a DCL-based dialog interface.

This function activates a dialog box definition specified by the dialog name and DCL file identifier. The dcl-id parameter references a loaded DCL resource obtained through load_dialog.

An optional action argument may specify a LISP callback function triggered on initialization. Provide an empty string (" ") to disable callback execution while maintaining positional parameters. This placeholder is required when specifying screen coordinates without functional activation.

Positional coordinates for the dialog's upper-left corner can be defined using the point parameter. Negative coordinate values (e.g., '(0 0)) will center the dialog within the application's display area by default.

Returns boolean T for successful dialog initialization; nil if the operation fails.

Examples

Code
(new_dialog "basedcl" dcl_id)
