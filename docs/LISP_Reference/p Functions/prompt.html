prompt

(prompt string)

Displays a message in the command line interface.

This function outputs textual content to both the active command line and historical prompt display. It interprets special formatting codes for enhanced terminal presentation.

Examples

Code Result
(prompt "zwcad") zwcadnil
(prompt "hello") hellonil

Note

The prompt function differs from LISP's output functions like princ, print, and prin1 by displaying messages solely in the Prompt History window without directing text to file streams.
