princ

(princ [expression [file-descriptor]])

Evaluates and outputs expressions with escaped character processing.

This function directs output to either the Command History panel or an open file. Specifying a file-descriptor parameter routes the output to that file; omitting it displays results in the interactive window.

Files must be initialized using the open function with write ("w") or append ("a") mode before receiving princ output.

The evaluated result of any expression type is displayed. Unlike prin1 and print, princ automatically processes escape sequences and does not add a trailing space or newline character.

Supported escape sequences include:

Escape Effect
\n Line feed (new line)
\t Horizontal tab
\r Carriage return
\\ Literal backslash
\" Double quote character
\e ESC control code (ASCII 27)
\ooo Octal character code (e.g. \101 = 'A')

Examples

Code Prints Result
(princ "hello") hello "hello"
(princ "\nName:") Name: "\nName:"
(princ "Thank you") Thank you "Thank you"

Note

The distinguishing feature of the princ function compared to LISP's output functions (such as print or prin1) is its treatment of control characters during processing.
