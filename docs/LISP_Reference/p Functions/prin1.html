prin1

(prin1 [expression [file-descriptor]])

Outputs an unformatted representation of the specified data.

This function directs output to either the ZWCAD command line interface or an open file. If a valid file descriptor is supplied, the result is written to the associated file. When omitted, output appears in the ZWCAD Interaction History panel without additional formatting characters.

The input expression accepts any valid data type and outputs its exact textual representation. No trailing spaces or line breaks are appended to the output.

When invoked without arguments, prin1 returns an empty string. This can be used to initialize files with zero-length content when writing to a file descriptor.

Files must be opened in write ('w') or append ('a') mode using the open function prior to using prin1 for file output operations.

Examples

Code Prints Result
(prin1 "hello") "hello" "hello"
(prin1 "\nName:") "\nName:" "\nName:"
(prin1 "Thank you") "Thank you" "Thank you"
