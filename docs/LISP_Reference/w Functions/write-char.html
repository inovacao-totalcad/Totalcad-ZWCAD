write-char

(write-char character [file-descriptor])

Outputs a single ASCII character to a specified file or interface.

The character argument must be an integer ASCII code. When a valid file-descriptor (obtained through the open function) is provided, the character is written to that file. If omitted, the output is directed to both the command line and Prompt History window.

Use the (ascii string)(IDR_128) function to convert characters to their corresponding ASCII codes. For string-based operations, consider using write-line instead for improved efficiency.

Implementation Note

While write-char provides low-level character control, most text operations benefit from using write-line for handling complete strings with automatic line termination.

Examples

Code Result
(write-char 97) a97
(write-char 109) m109

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (setq f (open "D:\\write-line.txt" "w")) (write-char 20320 f) (close f)

  • When LISPSYS is 1, the result is writing "你".
  • When LISPSYS is 0, the result may not be as expected.
