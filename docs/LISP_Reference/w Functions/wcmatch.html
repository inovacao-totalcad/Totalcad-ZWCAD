wcmatch

(wcmatch str pattern)

Performs advanced pattern matching on strings.

This function evaluates whether a target string contains specific character sequences or conforms to a defined format using wildcard operators. Applications include validation checks and selective string processing.

Example: To detect digits followed by special symbols in variable TXT containing "ZWCAD-2026$%^", execute:

(wcmatch TXT "*-####$*")

Returns T for successful matches, nil otherwise. Case sensitivity requires consistent casing - consider using strcase for normalization.

Pattern Operators

SymbolFunctionality
!Negation operator (exclude pattern)
%Single character wildcard (alphanumeric)
*Multi-character wildcard (zero or more)
^Escape character for literal interpretation
?Positional placeholder (exact position match)
[a-f]Character range inclusion (a to f)
{A,B,C}Alternation set (matches any listed option)
_Non-alphabetic character match
$Terminal match (end of string)
+Quantifier (one or more occurrences)

Examples

Code Result
(wcmatch "b" "[a-c]") T
(wcmatch "b" "?") T
(wcmatch "abc" "~w") T
