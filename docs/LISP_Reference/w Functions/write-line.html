write-line

(write-line string [file-descriptor])

Outputs a string to a file or interface.

This function provides enhanced performance compared to write-char and supports all string-formatted data. Specify a target file using a file-descriptor returned by the open function. If no file-descriptor is supplied, the string displays in both the command line and the Prompt History panel.

Examples

Code Result
(setq f (open "sample_file.txt" "w"))
(write-line "First Line Content" fil)
(close f) 		# "First Line Content" nil

Unicode support

The result of this function is affected by the LISPSYS system variable.

Example: (setq f (open "D:\\write-line.txt" "a")) (write-line "?????" f) (close f)

  • When LISPSYS is 1, the result is writing "?????".
  • When LISPSYS is 0, the result may not be as expected.
