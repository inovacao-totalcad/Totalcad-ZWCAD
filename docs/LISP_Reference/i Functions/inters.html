inters

(inters point1 point2 point3 point4 [flag])

Computes the intersection point between two line segments.

This function evaluates the crossing point of two finite lines defined by endpoint pairs (point1, point2) and (point3, point4). Returns nil if the segments do not overlap. The optional flag parameter determines line handling: when omitted or set to a non-nil value, only actual segment intersections are returned. If flag is explicitly set to nil, extended infinite lines are considered, returning their theoretical intersection point (or nil for parallel lines).

Examples

Code Result
(inters '(-2.7 6.4) '(-1 8.3) '(-1 6.9) '(-2 8)) (-1.63130 7.59443)
(inters '(-2 3) '(2 -4) '(4 1) '(3 1)) nil
