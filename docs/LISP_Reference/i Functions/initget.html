initget

(initget [flags] [keywords])

Defines input constraints and keyword options for subsequent user interaction functions.

This function configures validation rules and keyword lists for commands like getkword. The flags parameter combines bit-coded restrictions using summation, while keywords specify allowable textual responses.

Input validation flags:

FlagConstraint
1Requires explicit input (disables empty Enter response)
2Excludes zero values
4Blocks negative numbers
8Disables drawing limits check
32Enables dashed rubber-band visualization
64Restricts getdist to 2D input
128Overrides other constraints

Example: To enforce positive numbers with visual feedback (4+2+32), use flag 38 before calling input functions.

Keyword syntax rules:

  • Separate alternatives with spaces: "Yes No"
  • Capitalize abbreviation hints: "WAll,WA DOor,DO" accepts "wa" for WAll
  • Full caps require exact match: "TOTAL" mandates complete entry
  • Prefix ~ hides menu items: "~Secret"
  • Underscore links translations: "_FrenchMot FR" pairs localized/global terms
